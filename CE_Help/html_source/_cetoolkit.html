CalcExpress Toolkit includes the components listed below for building applications in LabVIEW. Each component features a dedicated set of VIs to perform specific tasks. These VIs are located on the CalcExpress sub-palette under the Functions >> Addons palette.

CSE is a script processor that executes scripts involving loops, conditional branches, and script calls, alongside functions for VI control, communication, synchronization, and other tasks.

CalcExpress is an expression evaluator and formula parser that provides polymorphism for its operators and functions. It supports development of user-defined functions as VIs.

VarMan is a variable manager that provides powerful data management for CalcExpress, CSE and LabVIEW VIs.

CE-Math is a collection of VIs that leverage CalcExpress to solve some mathematical tasks.

 

In addition, the toolkit provides several interactive utilities accessible via the Tools >> CalcExpress menu in the LabVIEW menu bar:

CSE ISP is an interactive script processor used to execute and test CSE scripts.

VarMan Spy is a utility designed to inspect VarMan objects and analyze their real-time properties.

CalcExpress Examples Navigator is a utility designed to browse and launch CalcExpress and CSE examples.

Mass compile CalcExpress VIs is a utility used to compile all CalcExpress VIs in bulk, including examples, utilities, and templates.
