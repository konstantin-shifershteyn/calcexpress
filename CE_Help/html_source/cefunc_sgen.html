GWNoise

The function generates a Gaussian white noise pattern.

The function is implemented as a FuncVI. To perform computation, it uses Gaussian White Noise.vi supplied with LabVIEW FDS and PDS. Refer to the help for this VI for more details.

Syntax

GWNoise(Ns ,std ,seed)

Description

The function returns an array containing a Gaussian-distributed pseudorandom sequence.

The function assigns an error code returned by the used LabVIEW VI to the rtErrorCode variable. You can evaluate it using the errno function. If this function completes successfully, the error code is zero.

Parameters

data type description
Ns DBL Number Optional parameter specifies a number of samples to generate. It is coerced to an integer to perform the function.
By default, it equals 128.
std DBL Number Optional parameter specifies the standard deviation of output sequence.
By default, it equals 1.
seed DBL Number Optional parameter reseeds a noise generator if it is greater than 0.
By default, it equals -1.

Return value

The function returns 1D Array of DBL that contains a Gaussian noise pattern.

SawtWave

The function generates an array containing a sawtooth wave.

The function is implemented as a FuncVI. To perform computation, it uses Sawtooth Wave.vi supplied with LabVIEW FDS and PDS. Refer to the help for this VI for more details.

Syntax

SawtWave(vn ,Ns ,F ,A ,phase)

Description

The function generates an array containing a sawtooth wave and writes it to the vn variable. The function returns the phase, in degrees, of the next sample of the sawtooth wave.

The function assigns an error code returned by the used LabVIEW VI to the rtErrorCode variable. You can evaluate it using the errno function. If this function completes successfully, the error code is zero.

Parameters

data type description
vn Identifier
(variable name)		 Required parameter specifies the name of an existing variable with the 1D array of DBL data type. The function writes the resulting array to this variable. If the variable does not exist or has another data type, an error occurs.
Ns DBL Number Optional parameter specifies a number of samples to generate. It is coerced to an integer to perform the function.
By default, it equals 128.
F DBL Number Optional parameter specifies the frequency, in cycles/sample units, of the sawtooth wave.
By default, it equals 1/128 (7.8125E-3) cycles/sample.
A DBL Number Optional parameter specifies the amplitude of the sawtooth wave.
By default, it equals 1.
phase DBL Number Optional parameter specifies the initial phase, in degrees, of the sawtooth wave.
By default, it equals 0.

Return value

The function returns DBL Number value that is the phase of the next sample of the sawtooth wave.
