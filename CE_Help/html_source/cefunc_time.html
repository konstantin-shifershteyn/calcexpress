GetTicks

The function returns the current value of the Milliseconds Timer.

Implementation: FastFunc, FuncVI.

Syntax

GetTicks()

Description

The function returns the value of the Milliseconds Timer (the output of the Tick Count (ms) primitive) in the range of 0 to 232-1.

Parameters

The function has no parameters.

Return value

The function returns a 32-bit unsigned integer value of the Milliseconds Timer represented as the DBL Number data type.

Comments

A Milliseconds Timer value is a 32-bit unsigned integer number. When it reaches 232-1, it wraps to 0 on the next increment. Use the u32sub function to reliably compute the difference between two timer values.

 

 

GetTime

The function returns the current date/time in the LabVIEW format.

Implementation: FastFunc, FuncVI.

Syntax

GetTime()

Description

The function returns the current date and time in seconds, in the universal LabVIEW date/time format; i.e., the number of seconds elapsed since 12:00 AM, January 1, 1904, UTC.

Parameters

The function has no parameters.

Return value

The function returns the time stamp represented as the DBL Number data type.

 

 

Wait

The function suspends the execution of a CalcExpress or CSE script for the specified time.

Implementation: FuncVI.

Syntax

Wait(ms)

Description

The function calls the Wait (ms) primitive to wait the number of milliseconds specified by ms.

Parameters

ms is the optional parameter that specifies the number of milliseconds for which the function should wait. It must have the DBL Number data type. If ms is not integer, the function coerces it to the integer. By default, ms equals zero.

Return value

The function returns a 32-bit unsigned integer value of the Milliseconds Timer when the wait expires, represented as the DBL Number data type.

Comments

A Milliseconds Timer value is a 32-bit unsigned integer number. When it reaches 232-1, it wraps to 0 on the next increment. Use the u32sub function to reliably compute the difference between two timer values.

 

 

WaitUntil

The function suspends the execution of a CalcExpress or CSE script until the millisecond timer becomes a multiple of the specified value.

Implementation: FuncVI.

Syntax

WaitUntil(ms)

Description

The function calls the Wait Until Next ms Multiple primitive to wait.

Parameters

ms is the optional parameter that specifies the millisecond multiple. It must have the DBL Number data type. If ms is not integer, the function coerces it to the integer. By default, ms equals zero.

Return value

The function returns a 32-bit unsigned integer value of the Milliseconds Timer when the wait expires, represented as the DBL Number data type.

Comments

A Milliseconds Timer value is a 32-bit unsigned integer number. When it reaches 232-1, it wraps to 0 on the next increment. Use the u32sub function to reliably compute the difference between two timer values.
