FastFunc functions

FastFunc is a name of function implementation designating embedded functions. Due to the fact FastFunc functions are integral part of CalcExpress kernel, they have two advantages:

  • FastFunc functions works faster than FuncVI
  • There are no additional resources required to perform FastFunc functions except a CalcExpress VI that evaluates expressions

Names of FastFunc functions are case-sensitive. To call a FastFunc function, you must use the exact name of the function as it is given in this manual.

If a function has both FastFunc and FuncVI implementations, you can choose which one to call to perform the function. Use the following rule:

  • use a function name the same as the function name in this manual to call the FastFunc
  • use a function name in different from the specified in this manual case to call the FuncVI

For example,  sin(x) is a call of FastFunc, but both Sin(x) and SIN(x) are calls of FuncVI.

 

 

FuncVI functions

FuncVI is a name of function implementation designating functions implemented as VI. FuncVI functions use LabVIEW features to be performed.

A name of FuncVI function is not case-sensitive. If a function has both FastFunc and FuncVI implementations, you can choose which one should be called to perform the function. Use the following rule:

  • use a function name the same as the function name in this manual to call the FastFunc
  • use a function name in different from the specified in this manual case to call the FuncVI

For example,  sin(x) is a call of FastFunc, but both Sin(x) and SIN(x) are calls of FuncVI.

 

IMPORTANT NOTICE: To use a FuncVI function in a built application (EXE), its corresponding VI must be included in the application build. There are several options to achieve this. For example, you can use a Static VI Reference to the FuncVI on your block diagram. Another standard option is to add the FuncVI files directly to your LabVIEW project tree and include them in the "Always Included" list of your application's build specifications.
