VI Control functions

The functions listed in this section are implemented as FuncVIs. When you call any of these functions, CalcExpress calls LabVIEW VI Server to perform the task. All the functions assign an error code, which LabVIEW returns, to the rtErrorCode variable.

Click on a function name below for detailed information on the function.

function quick info
viAbort(vi,fp) aborts the execution of the specified Virtual Instrument.
viCtrlGet(vi,cn,vn...) reads the values of FP Controls and Indicators of the specified Virtual Instrument.
viCtrlSet(vi,cn,x...) writes values to FP Controls of the specified Virtual Instrument.
viOpenFP(vi,open) opens or closes a Front Panel window of the specified Virtual Instrument.
viRun(vi,fp,cn,x...) starts the execution of the specified Virtual Instrument.
viState(vi,mod) returns a state of the specified Virtual Instrument.
