idn

The function converts its string parameter to an identifier.

Implementation: FastFunc.

Syntax

idn(name)

Description

The function returns a value that equals the string parameter name but has the Identifier data type, which is used to denote variable names and function names. This function is useful to specify a variable to access or a function to perform at run-time.

A call of this function has the same effect as if you explicitly write the identifier (a variable name or a function name) specified by name. For example, the following statements have the same effect:

x = y + sin(z);
idn("x") = idn("y") + idn("sin")(z);

This function can be used to access a variable by an alias associated with it. It is impossible to directly use a complete VarMan name specifier to access a variable by an alias because of non-strict alias syntax and using equality sign ( = ) to specify an alias (see Referring to variable topic). Use of this function eliminates this restriction. For example, if there is a variable existing in any context that has an associated alias equal to "Variable N", you can operate on it as shown below:

x = idn("=Variable N");
idn("=Variable N") = 5;
idn("=Variable N") += 1;

This function can be used to arrange an indirect function call when a desired function is chosen at run-time. Herewith, both FastFunc and FuncVI functions can be called using this technique. For example:

funcs = vector("sin","cos","tan","atan");
x = 1.0;
y = idn(funcs[2])(x);  // y is equal to tan(x)

Important notes.

  • The function does not check a correctness of the identifier; it merely converts its string parameter into an operand that has the Identifier data type.
  • If the function is used to specify a variable, either by name or by an alias, the function itself does not evaluate the variable. The variable will be evaluated later when its value is required to complete an expression evaluation. It can cause an error at script execution time if the specified variable does not exist.
  • The function can safely be used as the left-hand operand in simple assignment operator providing that a name specifier is correct. If the specified variable does not exist, it will be created.
  • If the function is used to specify a function name, the resulting function call cannot be validated during script parsing. Hence, it can cause an error at script execution time if the specified function does not exist or cannot operate on the specified set of parameters.

Parameters

data type description
name String Required parameter that specifies an identifier in the string representation.

Return value

The return value has the Identifier data type.

Example

/* It's example of CSE script */
x23 = "a variable";
msg = "VarName: x23";
/* extracts a variable name from a message */
varName = scanstr(msg, "VarName: %s");
if (vtest(varName) >= 0) {
   /* show a variable value if it exists */
   probe( idn(varName) );
}
else {
   MsgBox("Undefined variable: ",varName);
}

vnidn

The function converts its string parameter to an identifier.

Implementation: FastFunc.

Syntax

vnidn(name)

Description

This function performs the same operation as the idn function. See description of idn function for more information.

 

 

vnstr

The function converts an identifier to a string.

Implementation: FastFunc.

Syntax

vnstr(ident)

Description

The function returns a string that has the same value as the identifier name specified by ident parameter. The function can be used to represent an identifier as a string at run time.

Call of this function has the same effect as if you explicitly write a string constant containing the identifier specified by name. For example, the following two statements have the identical effect:

vtest("ident");
vtest(vnstr(ident));

Note that the function does not evaluate the specified variable, it merely converts the identifier name to a string. Therefore, no error occurs if the identifier denotes a non-existent variable.

Parameters

data type description
ident Identifier required parameter that specifies an identifier to be converted to a string.

Return value

The return value has the String data type.

Example

/*
It's example of CSE script.
*/
varName = vnstr(param10);
type = vtest(varName);
if (type >= 0)
   MsgBox( sform("Variable %s has type %d",varName,type));
else
   MsgBox( sform("Variable %s doesn't exist", varName));
