NotifCancel

The function erases any message in a notifier with the specified name.

Implementation: FuncVI.

Syntax

NotifCancel(name)

Description

The function erases any message in the notifier specified by the name parameter. The function works with LabVIEW notifiers that handle string data.

The function assigns an error code returned by the used LabVIEW functions to the rtErrorCode variable. You can evaluate it using the errno function. If this function completes successfully, the error code is zero.

Parameters

data typedescription
name String Required parameter that specifies the name of the notifier.

Return value

The function returns a cancelled notification or an empty string if there is no active notification available.

The return value has the String data type.

NotifCreate

The function creates a notifier with the specified name.

Implementation: FuncVI.

Syntax

NotifCreate(name)

Description

The function creates a new notifier with the specified name unless a notifier with the same name already exists. The function works with LabVIEW notifiers that handle string data.

The function assigns an error code returned by the used LabVIEW functions to the rtErrorCode variable. You can evaluate it using the errno function. If this function completes successfully, the error code is zero.

Parameters

data typedescription
name String Required parameter that specifies the name of the notifier.

Return value

The function returns 1 (TRUE) if a new notifier is created; otherwise, it returns 0 (FALSE).

The return value has the DBL Number data type.

Example

/* It's example of CSE script */
notifName = "Notifier";
if (NotifCreate(notifName)) {
  MsgBox("New notifier is created");
}
else {
  if (errno())
     lvErrorMessage("Create Notifier Error");
  else
     MsgBox("Notifier already exists");
}

NotifDestroy

The function destroys a notifier with the specified name.

Implementation: FuncVI.

Syntax

NotifDestroy(name)

Description

The function destroys a notifier with the name specified by the name parameter. The function works with LabVIEW notifiers that handle string data.

The function assigns an error code returned by the used LabVIEW functions to the rtErrorCode variable. You can evaluate it using the errno function. If this function completes successfully, the error code is zero.

Parameters

data typedescription
name String Required parameter that specifies the name of the notifier.

Return value

The function returns the last notification sent to the destroyed notifier or an empty string.

The return value has the String data type.

Example

/* It's example of CSE script */
notifName = "Notifier";
msg = NotifDestroy(notifName);
if (errno())
   lvErrorMessage("Destroy Notifier Error");
else
   MsgBox("Notifier is destroyed.\n"
          "The last notification:\n", msg);

NotifSend

The function sends a notification to the specified notifier.

Implementation: FuncVI.

Syntax

NotifSend(name ,msg)

Description

The function sends notification to the notifier specified by the name parameter. The msg parameter specifies a string message to be sent to the notifier. All functions and VIs waiting on this notifier finish waiting and return the sent message. The function works with LabVIEW notifiers that handle string data.

The function assigns an error code returned by the used LabVIEW functions to the rtErrorCode variable. You can evaluate it using the errno function. If this function completes successfully, the error code is zero.

Parameters

data typedescription
name String Required parameter that specifies the name of the notifier.
msg String Optional parameter that defines a message to send to the notifier. By default, msg is an empty string.

Return value

The function returns an error code that has the same value as the rtErrorCode variable. If no error occured, the function returns zero.

The return value has the DBL Number data type.

Example

/* It's example of CSE script */
notifName = "Notifier";
if (NotifSend(notifName, "STOP")) {
   /* on an error */
   lvErrorMessage("Send Notification Error");
}

Synchronization functions.

 

 

NotifTest

The function tests if a notifier with the given name exists.

Implementation: FuncVI.

Syntax

NotifTest(name)

Description

The function returns 1 (TRUE) if a notifier with the specified name exists. Otherwise, it returns 0 (FALSE). The function works with LabVIEW notifiers that handle string data.

The function does not change the value of the rtErrorCode variable.

Parameters

data typedescription
name String Required parameter that specifies the name of the notifier.

Return value

The function returns 1 (TRUE) if a notifier with the given name is found, or 0 (FALSE) otherwise.

The return value has the DBL Number data type.

Example

/* It's example of CSE script */
notifName = "Notifier";
if (NotifTest(notifName))
   MsgBox("Notifier exists");
else
   MsgBox("Notifier doesn't exist");

NotifWait

The function waits for a notification sent to the specified notifier.

Implementation: FuncVI.

Syntax

NotifWait(name ,tmo ,ignore)

Description

The function waits for a notification sent to the notifier specified by the name parameter. The function works with LabVIEW notifiers that handle string data.

The function waits until either notification is sent to the specified notifier or the specified timeout expires. If the function finishes by timeout, it assigns the error code 56 to the rtErrorCode variable. Otherwise, the function returns a notification it has received.

If ignore (previous) parameter is zero (FALSE) and a notification was sent to the notifier since the last call of the function, the function immediately returns the old notification.

The function assigns an error code returned by the used LabVIEW functions to the rtErrorCode variable. You can evaluate it using the errno function. If this function completes successfully, the error code is zero.

Parameters

data typedescription
name String Required parameter that specifies the name of the notifier.
tmo DBL Number Optional parameter that specifies the timeout value in milliseconds. To specify infinite timeout, set tmo to -1. By default, tmo equals 1000 milliseconds.
ignore DBL Number optional parameter. If its value coerced to an integer is not zero, the function ignores notifications sent before this function is called. By default, ignore is 1 (TRUE).

Return value

On success, the function returns the last notification sent to the notifier name.

The return value has the String data type.

Example

/* It's example of CSE script */
notifName = "Notifier";
msg = NotifWait(notifName, 0);
while(errno() == 56) {
  msg = NotifWait(notifName, 1000, 0);
}
if (errno() == 0)
  MsgBox("Notification is received:\n", msg);
else
  lvErrorMessage("Wait Notification Error");
