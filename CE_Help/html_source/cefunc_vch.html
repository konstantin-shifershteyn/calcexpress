vch

The function returns the handle of a variable context.

Implementation: FastFunc.

Syntax

vch(name)

Description

If the optional parameter name is omitted in a function call or is an empty string, the function returns a handle of the variable context used by a CalcExpress VI or CSE VI that is executing the script. Otherwise, it looks for a context with the specified name and returns its handle.

On success, the function returns the context handle. Otherwise, it returns the negated value of the VarMan Engine error code indicating an error reason. For example, it returns -18 if a context with the specified name was not found.

Parameters

data typedescription
name String Optional parameter that specifies a variable context name.

Return value

The function returns either a variable context handle or an error code (see above).

The return value has the DBL Number data type.

vchtest

The function validates a handle of variable context.

Implementation: FastFunc.

Syntax

vchtest(vch)

Description

The function checks if the vch parameter is a valid handle of a local variable context. If vch is omitted in a function call, the function checks the handle of the variable context used by a CalcExpress VI or CSE VI executing the script.

On success, the function returns zero. Otherwise, it returns the negated value of the VarMan Engine error code indicating an error reason. For example, it returns -4 if an invalid context handle was specified.

Parameters

data typedescription
vch DBL Number Optional parameter that specifies a variable context handle. If vch is equal to 0 or omitted, the handle of the current context is assumed. By default, vch is equal to 0.

Return value

The function returns an execution status code (see above).

The return value has the DBL Number data type.

vcname

The function returns a name assigned to the specified variable context.

Implementation: FastFunc.

Syntax

vcname(vch)

Description

The function returns the name of the variable context specified by the vch parameter. If vch is omitted in a function call, the function returns the name of the variable context used by a CalcExpress VI or CSE VI executing the script. If vch is not a valid handle, or if it refers to a context that does not have a name, the function returns an empty string.

Parameters

data typedescription
vch DBL Number Optional parameter that specifies a variable context handle. If vch is equal to 0 or omitted, the handle of the current context is assumed. By default, vch is equal to 0.

Return value

The function returns the name of the variable context.

The return value has the String data type.
