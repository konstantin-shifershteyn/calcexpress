scmp , sccmp

The functions compare strings.

Implementation: FastFunc.

Syntax

scmp(s1,s2)
sccmp(s1,s2)

Description

Both functions lexically compare strings specified by the s1 and s2 parameters. The functions operate identically, except that the scmp function performs a case-sensitive comparison, while the sccmp function performs case-insensitive comparison.

The functions return a numeric value that expresses a relationship of s1 and s2 as the following:

-1  if  s1 is less than s2
 0  if  s1 is identical to s2
 1  if  s1 is greater than s2

The functions can operate on strings, arrays of strings, and combinations thereof. However, not all combinations are supported. A list of valid combinations is provided below.

String - String.  The functions compare strings and return a scalar value.

String - Array of any dimensionality.  The functions compare the input string with each element of the input array. They return a numeric array with the same dimensionality and size as the input array, where each element in the returned array contains a relationship between the corresponding element in the input array and the input string.

1D Array - 1D Array.  The functions compare the respective elements in the input arrays. They return a numeric array of the same size as the smallest input array, where each element contains a relationship between the corresponding elements in the input arrays.

Parameters

data type description
s1, s2 String
1D array of Strings
2D array of Strings		 Required parameters. Valid combinations of their types are the following:
string - string,
string - nD array,
1D array - 1D array

Return value

The functions return DBL Number if both s1 and s2 are Strings.

The functions return 1D Array of DBL if s1 or s2, or both of them, are 1D Array of Strings.

The functions return 2D Array of DBL if either s1 or s2 is 2D Array of Strings.

Example

/* 1D array of strings */
sarr = vector("ab","abc","abcd","ABC");
r1 = scmp("abc", sarr);   /* returns array {1,0,-1,1} */
r2 = sccmp(sarr, "ABC");  /* returns array {-1,0,1,0} */
probe(r1, "r1");
probe(r2, "r2");

sform

The function converts the input values into a single string according to the specified format.

Implementation: FuncVI. The FuncVI uses Format Into String LabVIEW function. Refer to the help for it for more information.

Syntax

sform(fmt ,x1 ... ,xn)

Description

The function converts the x parameters to a resulting string according to the format specified by the fmt parameter. All predefined data types are supported for the x parameters.

Details
The function splits fmt into a set of format substrings and verbatim substrings. It then operates on each element of this set, producing a string that is added to the final string. The function merely copies the verbatim substrings, and uses the format substrings to convert the corresponding x parameters into strings using the Format Into String LabVIEW function.
A format substring starts with a format specifier (%-sequence) and lasts until the next format specifier or the end of the format string. Thus, a format substring consists of a format specifier followed by an optional literal substring; for example, "%f volts".
A substring before the first format specifier makes an initial verbatim substring. Additional verbatim substrings can be explicitly defined using a sub-delimiter ( %| ), see below for more information.

If all x parameters are numbers and/or strings, the function works similarly to the Format Into String LabVIEW function or the printf function in C.

If any x is an array, the function applies the corresponding format substring to each element in the array and concatenates the results into a single string.

The function supports a non-standard sub-delimiter ( %| ), which is used to explicitly separate substrings in a format string. Every time the function encounters this sub-delimiter, it terminates the current substring (format or verbatim) and starts a new one. This is useful to precise a format substring when the corresponding x is an array, as the format substring will be applied to each element of the array.

The function assigns an error code returned by the used LabVIEW functions to the rtErrorCode variable. You can evaluate it using the errno function. If this function completes successfully, the error code is zero.

Parameters

data type description
fmt String Required parameter specifies the format string for Format Into String LabVIEW function. Refer to the help for this function for information on the format specification.
In addition, the function supports a non-standard sub-delimiter ( %| ) that is used to explicitly separate format and/or verbatim substrings.
x1...xn any predefined Optional parameters that need be converted to a string.

Return value

The function returns the resulting String.

Example

x = 0.5;  u = "radians";
s0 = sform("atan(%.2f) equals %e %s", x, atan(x), u);
/* returns the string "atan(0.50) equals 4.636476E-1 radians" */

/* --------
The following example demonstrates a use of
array parameters and the sub-delimiter
----------- */
arr = vector(3,5,7);     //1D array

// *** no sub-delimiter
s1 = sform("Values:\nU=%.1f Volt\n", arr);

// *** one sub-delimiter
s2 = sform("Values:\n%|U=%.1f Volt\n", arr);

// *** two sub-delimiters
s3 = sform("Values:\n%|U=%.1f\n%|All in volts\n", arr);
/*
after the code above is completed we have the following result
s1 contains s2 contains s3 contains
Values:
U=3.0 Volt
5.0 Volt
7.0 Volt
 Values:
U=3.0 Volt
U=5.0 Volt
U=7.0 Volt
 Values:
U=3.0
U=5.0
U=7.0
All in volts
*/
probe(s0, "s0");
probe(s1, "s1");
probe(s2, "s2");
probe(s3, "s3");

data type description

> 0 : a substring after the match.

The function returns the value with the same data type as str; i.e. it can be String, 1D Array of Strings or 2D Array of Strings.

The function returns String if both s1 and s2 are strings.

The function returns 1D Array of Strings if at least one of s1 and s2 is 1D array and the other is not 2D array.

The function returns 2D Array of Strings if at least one of s1 and s2 is 2D array.

Example

s1d = vector("+5","+12","-12"); /* 1D array of strings */
s2d = matrix(                   /* 2D array of strings */
       vector("A1","A2","A3"),
       vector("B1","B2","B3"),
       vector("C1","C2","C3")
      );
s1o = smix(s1d, "V"); /* s1o is {"+5V", "+12V", "-12V"} */
s1o = smix("U=",s1o); /* s1o is {"U=+5V", "U=+12V", "U=-12V"} */

s2o = smix(s2d, smix(" : ", s1o), 0);
/* -- s2o is 2D array --
  {{"A1 : U=+5V", "A2 : U=+12V", "A3 : U=-12V"},
   {"B1 : U=+5V", "B2 : U=+12V", "B3 : U=-12V"},
   {"C1 : U=+5V", "C2 : U=+12V", "C3 : U=-12V"}}
*/

s3o = smix(smix(s1o, " : "), s2d, 1);
/* -- s3o is 2D array --
  {{"U=+5V : A1" , "U=+5V : A2" , "U=+5V : A3"},
   {"U=+12V : B1", "U=+12V : B2", "U=+12V : B3"},
   {"U=-12V : C1", "U=-12V : C2", "U=-12V : C3"}}
*/
probe(s1o, "s1o");
probe(s2o, "s2o");
probe(s3o, "s3o");
