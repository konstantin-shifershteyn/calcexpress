APSpectrum

The function computes the single-sided, scaled, auto power spectrum of a time-domain signal.

The function is implemented as a FuncVI. To perform computation, it uses Auto Power Spectrum.vi supplied with LabVIEW FDS and PDS. Refer to the help for this VI for more details.

Syntax

APSpectrum(x,vnMag ,dt)

Description

The function computes the auto power spectrum of the time-domain signal x, sampled with the period dt, and writes it to the vnMag variable.

The resulting power spectrum is in input signal units rms squared; e.g. if x is in volts, vnMag is in volts rms squared.

The function returns the line frequency interval df of the power spectrum. df is in Hertz if dt is in seconds.

Parameters

data type description
x 1D array of DBL Input time-domain signal (required parameter).
vnMag Identifier
(variable name)		 Required parameter specifies the name of an existing variable with the 1D array of DBL data type. The function writes the auto power spectrum to this variable. If the variable does not exist or has another data type, an error occurs.
dt DBL Number Optional parameter specifies the sample period of the time-domain signal x, typically in seconds.
By default, it equals 1.

Return value

The function returns DBL Number value that is the line frequency interval of the auto power spectrum.

CPSpectrum

The function computes the single-sided, scaled, cross power spectrum of two time-domain signals. It produces both the magnitude and phase of the cross power spectrum.

The function is implemented as a FuncVI. To perform computation, it uses Cross Power Spectrum.vi supplied with LabVIEW FDS and PDS. Refer to the help for this VI for more details.

Syntax

CPSpectrum(x,y,vnMag ,dt ,vnPhase)

Description

The function computes the cross power spectrum of two time-domain signals x and y, sampled with the period dt. The function writes the power spectrum magnitude to the vnMag variable, and the spectrum phase to the vnPhase variable unless it is omitted in a function call.

The resulting power spectrum magnitude is in input signal units rms squared; e.g. if x and y are in volts, vnMag is in volts rms squared. The resulting spectrum phase (vnPhase) is in radians, it shows the difference between phases of the x and y.

The function returns the line frequency interval df of the cross power spectrum. df is in Hertz if dt is in seconds.

Parameters

data type description
x 1D array of DBL 1st input time-domain signal (required parameter)
y 1D array of DBL 2nd input time-domain signal (required parameter)
vnMag Identifier
(variable name)		 Required parameter specifies the name of an existing variable with the 1D array of DBL data type. The function writes the cross power spectrum magnitude to this variable. If the variable does not exist or has another data type, an error occurs.
dt DBL Number Optional parameter specifies the sample period of the time-domain signals x and y, typically in seconds.
By default, it equals 1.
vnPhase Identifier
(variable name)		 Optional parameter specifies the name of an existing variable with the 1D array of DBL data type. The function writes the spectrum phase to this variable unless it is omitted in the function call. If the variable does not exist or has another data type, an error occurs.

Return value

The function returns DBL Number value that is the line frequency interval of the cross power spectrum.

decimate

The function decimates an input sequence by the specified decimating factor.

Implementation: FastFunc, FuncVI.

Syntax

decimate(x ,dcf ,ave)

Description

The function decimates the sequence x according to the specified decimating factor dcf and the averaging option ave. It returns the decimated array.

If Y represents the decimated array then

if ave is false (zero)

Y[i] = x[i*dcf]

if ave is true (non-zero)

Y[i] = (x[i*dcf] + x[i*dcf+1] +...+ x[i*dcf+dcf-1])/dcf

for i = 0,1,...,N-1,  where N is the size of decimated array

N = floor(size(x)/dcf)

The function assigns an error code returned by the used LabVIEW VI to the rtErrorCode variable. You can evaluate it using the errno function. If this function completes successfully, the error code is zero.

Parameters

data type description
x 1D array of DBL Input sequence (required parameter).
dcf DBL Number Optional parameter specifies the decimating factor. The function coerces it to an integer value. dcf must be greater than zero and less than or equal to the size of x.
By default, it equals 2.
ave DBL Number Optional parameter specifies averaging option. Averaging is enabled, if ave coerced to the integer is non-zero.
By default, it equals 0.

Return value

The function returns 1D Array of DBL that contains the decimated array.
