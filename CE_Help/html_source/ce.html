CalcExpress Overview

CalcExpress is a collection of VIs used to evaluate string-based expressions and formulas at runtime. The engine evaluates linear scripts containing one or more expressions. If execution requires complex scripting capabilities involving loops, branches, or script calls, the CSE (CalcExpress Script Engine) must be used instead.

CalcExpress provides a large set of operators and functions; all operators are polymorphic as well as many of the functions. Furthermore, the function set can be extended by adding custom functions developed as VIs (named FuncVI). Variables within expressions and scripts are managed via VarMan, allowing them to be used locally within a single script or shared across VIs to pass parameters using VarMan VIs.
