CalcExpress Expression Syntax

CalcExpress evaluates linear scripts containing one or more expressions. An expression is sequence of operands, operators, and function calls that performs any sequential actions to compute a value (the expression value). Besides, an expression can produce side effects if it involves variable assignments and-or function calls. If you need to perform a script that involves loops and/or conditional branches, use CSE (CalcExpress Script Engine) that is CalcExpress superset.

To combine a few expressions into a single script a semicolon, that is an expression terminator, is used. An expression that is followed by a semicolon is an expression-statement. An expression-statement must contain a complete expression; i.e. CalcExpress must be able to fully evaluate it according to the rules for applying operators. CalcExpress evaluates an expression-statement completely (including all side effects) before starting to evaluate the next one. See Order of Script Evaluation topic.

CalcExpress VIs can directly return the value of the last expression in a script, as long as it is not an expression-statement (i.e., it does not end with a semicolon). You can use this feature to obtain the value of an expression in your VIs (another way is to pass values through variables).

Operands are entities that operators act on. Constants, variables, the values returned by functions, and the results of operator evaluations are all operands. Each operand is characterized by its value and data type. If an expression consists of an operand only, the expression value equals the operand's value. The value of a blank expression (which contains no operands) is undefined.

Operators perform actions on operands. Operators acting on a single operand are called unary operators. Operators acting on two operands are called binary operators. CalcExpress operators are polymorphic; it means they can act on operands of different predefined data types as well as combinations thereof (for binary operators). A few operators support user-defined data types.

Functions are used to perform more complex tasks than operators can do. When a function is called, it receives passed parameters, performs a specific task and returns a result value. Furthermore, a function can produce side effects; for example, it can change a variable value, open a dialog window, send a notification, etc. CalcExpress has a large set of predefined functions. In addition, CalcExpress provides the ability to implement custom functions as VIs (known as FuncVI) and call them in a script in the same way as you would call predefined functions.

In order to document a script, comments are used. CalcExpress supports both single-line and multi-line comments.
