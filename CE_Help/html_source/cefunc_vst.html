vstcid

The function returns the variable's Creator ID, which is the Writer ID value defined when the variable was created.

Implementation: FastFunc.

Syntax

vstcid(name ,vch)

Description

The function returns the Writer ID value defined when the variable was created. If an error occurs, it returns the negated value of the VarMan Engine error code indicating the cause of the error. For example, it returns -2 if the variable is not found, or -4 if an invalid context handle is provided.

The optional parameter vch defines the handle of the variable context in which the variable name exists. If vch is omitted in the function call, the function defaults to the handle of the current local context passed to the CalcExpress or CSE VI executing the script (the current local context). vch is ignored if name refers to a variable by an alias.

Parameters

  data type description
name String Required parameter that specifies a variable name. In general, name must comply with the VarMan name specifier syntax and can include a variable name or an alias, or both. See the Referring to variables topic for more information.
vch DBL Number Optional parameter that specifies the handle of the variable context where the specified variable exists. It is ignored if name refers to a variable by an alias. There are two special values for vch:
vch equal to 0 denotes the current local context.
vch equal to -1 denotes the global context.
By default, vch is equal to 0.

Return value

The function returns a 32-bit unsigned integer value on success, or a negated error code on failure, represented as the DBL Number data type.

Example

x = 1;
for (i=1; i<=10; i++) {
   vwrid(i); /* set script's WriterID to the loop index */
   x += x; /* modify the variable */
}
probe( vstcid("x"), "WriterID when the variable was created");
probe( vstwid("x"), "WriterID for the most recent value");

vstcms

The function returns the Milliseconds Timer value when the variable was created.

Implementation: FastFunc.

Syntax

vstcms(name ,vch)

Description

The function returns the Milliseconds Timer value (the output of the Tick Count (ms) primitive) when the variable was created. If an error occurs, it returns the negated value of the VarMan Engine error code indicating the cause of the error. For example, it returns -2 if the variable is not found, or -4 if an invalid context handle is provided.

The optional parameter vch defines the handle of the variable context in which the variable name exists. If vch is omitted in the function call, the function defaults to the handle of the current local context passed to the CalcExpress or CSE VI executing the script (the current local context). vch is ignored if name refers to a variable by an alias.

  data type description

vch DBL Number Optional parameter that specifies the handle of the variable context where the specified variable exists. It is ignored if name refers to a variable by an alias. There are two special values for vch:

By default, vch is equal to 0.

vtype

The function returns the data type code of the given variable.

Implementation: FastFunc.

Syntax

vtype(name ,vch)

Description

The function returns the data type code of the specified variable. If an error occurs, it returns the negated value of the VarMan Engine error code indicating the cause of the error. For example, it returns -2 if the variable is not found, or -4 if an invalid context handle is provided.

The optional parameter vch defines the handle of the variable context in which the variable name exists. If vch is omitted in the function call, the function defaults to the handle of the current local context passed to the CalcExpress or CSE VI executing the script (the current local context). vch is ignored if name refers to a variable by an alias.

Parameters

  data type description
name String Required parameter that specifies a variable name. In general, name must comply with the VarMan name specifier syntax and can include a variable name or an alias, or both. See the Referring to variables topic for more information.
vch DBL Number Optional parameter that specifies the handle of the variable context where the specified variable exists. It is ignored if name refers to a variable by an alias. There are two special values for vch:
vch equal to 0 denotes the current local context.
vch equal to -1 denotes the global context.
By default, vch is equal to 0.

Return value

The function returns a positive data type code on success, or a negated error code on failure, represented as the DBL Number data type.

Example

varName = "X10";

/* Determines a context handle by the context name */
varCntx = vch("Object A12 Parameters");

/* Determine a type of the variable */
type = vtype(varName, varCntx);

if (type < 0) {        /* If an error */
   if (type == -4)
      MsgBox("The specified context doesn't exist");
   else
      MsgBox("Variable is not defined: ", varName);
}
else
   MsgBox("Data type code: ", type);

vwrid

The function defines or returns the Writer ID value applied to variable write operations executed by the running CalcExpress or CSE instance.

Implementation: FastFunc.

Syntax

vwrid(writerID)

Description

The optional parameter writerID specifies a new Writer ID value for the instance. If writerID is omitted in the function call, the function returns the current Writer ID value of the CalcExpress or CSE instance without modifying it.

Every CalcExpress and CSE instance holds its own Writer ID value, which is passed to VarMan during variable write operations. This value is initialized to 0 when the instance is created, but it can be altered before execution using relevant CalcExpress or CSE VIs, or during script execution using this function. A new value stays unchanged until it is explicitly altered again.

Writer ID is a 32-bit unsigned integer value; hence, writerID must be in the range of 0 to 232-1.

Parameters

  data type description
writerID DBL Number Optional parameter that specifies a new Writer ID value for the running CalcExpress or CSE instance.
 

Return value

The function returns a 32-bit unsigned integer number, which is the Writer ID value of the running instance prior to this function call, represented as the DBL Number data type.

Example

probe( vwrid(), "Original WriterID");
vwrid(1000); /* set new script's WriterID */
x = 1;
for (i=1; i<=10; i++) {
   vwrid(i); /* set script's WriterID to the loop index */
   x += x; /* modify the variable */
}
probe( vstcid("x"), "WriterID when the variable was created");
probe( vstwid("x"), "WriterID for the most recent value");
