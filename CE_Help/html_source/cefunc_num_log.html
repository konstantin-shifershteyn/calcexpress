exp

The function computes the exponential.

Implementation: FastFunc, FuncVI.

Syntax

exp(x)

Description

The function returns the value of e raised to the x power.

Parameters

The function can operate on scalars and arrays. The result is produced according to the polymorphism rules. Formally, x can have the following data types:

DBL Number 1D Array of DBL 2D Array of DBL
CDB Number 1D Array of CDB 2D Array of CDB

click here for general information on data types.

Return value

The function returns a value that has the same data type as x.

 

 

ln

The function computes the natural logarithm.

Implementation: FastFunc, FuncVI.

Syntax

ln(x)

Description

The function returns the natural logarithm of x. If x is 0, the function returns -Inf. If x is less than 0, the function returns NaN unless x has complex representation.

Parameters

The function can operate on scalars and arrays. The result is produced according to the polymorphism rules. Formally, x can have the following data types:

DBL Number 1D Array of DBL 2D Array of DBL
CDB Number 1D Array of CDB 2D Array of CDB

click here for general information on data types.

Return value

The function returns a value that has the same data type as x.

 

 

log

The function computes the logarithm to the specified base.

Implementation: FastFunc, FuncVI.

Syntax

log(x,y)

Description

The function returns the logarithm of y to the base x. If y is 0, the function returns -Inf. If x is less than or equal to 0, or y is less than 0, the function returns NaN unless at least one of x and y has complex representation.

Parameters

The function can operate on scalars, arrays, and combination thereof. The result is produced according to the polymorphism rules. Formally, x and y can have the following data types:

DBL Number 1D Array of DBL 2D Array of DBL
CDB Number 1D Array of CDB 2D Array of CDB

click here for general information on data types.

Return value

Type of return value is determined by the polymorphism rules for function with two arguments.

pow

The function computes x raised to the y power.

Implementation: FastFunc, FuncVI.

Syntax

pow(x,y)

Description

The function returns the x raised to the power of y. If y is zero, the function returns 1 for any value of x. If x is less than 0 and y is not integer, the function returns NaN. If x is 0 and y is negative, the function returns Inf unless x or y is complex.

Parameters

The function can operate on scalars, arrays, and combinations thereof. The result is produced according to the polymorphism rules. Formally, x and y can have the following data types:

DBL Number 1D Array of DBL 2D Array of DBL
CDB Number 1D Array of CDB 2D Array of CDB

click here for general information on data types.

Return value

Type of return value is determined by the polymorphism rules for function with two arguments.
