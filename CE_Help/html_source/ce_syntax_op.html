Operators

Operators are used to perform actions on operands. An operand is a value or expression that an operator acts on. There are the following types of operators:

  • Unary operators perform operations on a single operand
  • Binary operators perform operations on two operands
  • Punctuators influence the order of expression evaluation
  • Subscript operator

All CalcExpress operators are polymorphic, which means they can act on operands of multiple data types. Most operators operate only on predefined data types, but some can handle user-defined data types as well. The description of each operator includes a list of supported data types. Click here for more information on polymorphism for operators.

Order of Evaluation

CalcExpress evaluates linear (sequential) scripts. A script may consist of a single expression or a sequence of expression-statements, which may be followed by another expression (meaning that the semicolon may be omitted at the end of the script).

If an expression is followed by a semicolon ( ; ), it is an expression-statement. Expression-statements are evaluated in the order they appear in a script. CalcExpress completely evaluates an expression statement, including all side effects, before beginning to evaluate the next expression or expression-statement.

Expressions are evaluated in the order determined by the precedence and associativity of operators used. To change this order, you can use parentheses to group expressions that need to be evaluated first. Note that parentheses are also used to denote function calls (see Function Call syntax topic).

High-precedence operators are evaluated first. If there are several operators with the same precedence, they are evaluated according to their associativity order. Expressions enclosed in parentheses () and brackets [] are evaluated before their values are used. The deeper an expression is nested, the earlier it is evaluated.
