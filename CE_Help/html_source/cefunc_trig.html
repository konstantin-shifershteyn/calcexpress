acos

The function computes the inverse cosine.

Implementation: FastFunc, FuncVI.

Syntax

acos(x)

Description

The function returns the arccosine of x in radians. For real numbers, the function returns values in the range 0 to pi; if x is less than -1 or greater than 1, the function returns NaN.

Parameters

The function can operate on scalars and arrays. The result is produced according to the polymorphism rules. Formally, x can have the following data types:

DBL Number 1D Array of DBL 2D Array of DBL
CDB Number 1D Array of CDB 2D Array of CDB

click here for general information on data types.

Return value

The function returns a value that has the same data type as x.

Comment

For complex arguments the acos function is computed with the formula:

-i * ln(x+sqrt(x*x-1))
