errno

The function provides access to the rtErrorCode variable.

Implementation: FastFunc.

Syntax

errno(errCode)

Description

If the function is called without a parameter, it returns the current value of rtErrorCode.

If the function is called with the errCode parameter, it assigns the value of errCode, coerced to an integer, to the rtErrorCode variable and returns the previous value of rtErrorCode.

Parameters

errCode is an optional parameter. If it is not omitted in a function call, errCode must have DBL Number data type. The function coerces it to an integer before assigning to rtErrorCode.

Return value

The function returns an integer value of the DBL Number data type. The value is zero if the last call of a function that assigns an error status to the rtErrorCode is successfully completed. On an error, the value is non-zero error code indicating a LabVIEW error status. Note that not all functions store an error status in rtErrorCode; refer to the function description to check if it has this capability.

See also

lvErrorMessage , lvErrorString

 

 

lvErrorMessage

The function opens a dialog box containing a LabVIEW error message if the specified error code indicates a LabVIEW error.

Implementation: FuncVI.

Syntax

lvErrorMessage(errSource ,errCode)

Description

The function is implemented as FuncVI. It calls LabVIEW Simple Error Handler.vi and passes to it either errCode value, if it is not omitted in a function call, or the rtErrorCode value otherwise. The VI opens a dialog box with a message describing the error unless the error code is equal to zero.

Parameters

errSource is optional parameter of the String data type. You can use this parameter to identify location of the function which has opened an error message box. It has the same meaning as error source control of Simple Error Handler.vi. If errSource is omitted in a function call, it defaults to the "rtErrorCode variable" string.

errCode is an optional parameter that spcifies a LabVIEW error code. If it is specified in a function call, errCode must have the DBL Number data type (note that the function coerces it to an integer). If it is omitted, the function uses the current value of the rtErrorCode instead of it.

click here for general information on data types.

Return value

The function returns an integer value of the DBL Number data type. The function returns the value of errCode coerced to an integer if it is not omitted, or the rtErrorCode value otherwise.

lvErrorString

The function returns a string containing an error message describing the specified LabVIEW error code.

Implementation: FuncVI.

Syntax

lvErrorString(errCode)

Description

The function is implemented as FuncVI. It calls LabVIEW Simple Error Handler.vi to produce an error message from either errCode parameter or the rtErrorCode variable.

Parameters

errCode is an optional parameter that spcifies a LabVIEW error code. If it is specified in a function call, errCode must have the DBL Number data type (note that the function coerces it to an integer). If it is omitted, the function uses the current value of rtErrorCode instead of it.

click here for general information on data types.

Return value

The function returns the String describing an error.
