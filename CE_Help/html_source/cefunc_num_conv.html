ceil

The function computes the ceiling of a real number.

Implementation: FastFunc.

Syntax

ceil(x)

Description

The function returns the smallest integer that is greater than or equal to x.

Parameters

The function can operate on scalars and arrays. The result is produced according to the polymorphism rules. Formally, x can have the following data types:

DBL Number 1D Array of DBL 2D Array of DBL

click here for general information on data types.

Return value

The function returns a value with the same data type as x.

Example

ceil( 3.04);  // returns  4
ceil( 3.96);  // returns  4
ceil(-3.04);  // returns -3
ceil(-3.96);  // returns -3

 

 

_finite, isfinite

The functions test a real number to determine whether it is finite.

Implementation: FastFunc.

Syntax

_finite(x)
isfinite(x)

Description

The functions return 1 (TRUE) if x is finite. The functions return 0 (FALSE) if x is one of NaN, +Inf, or -Inf.

Parameters

The functions can operate on scalars and arrays. The result is produced according to the polymorphism rules. Formally, x can have the following data types:

DBL Number 1D Array of DBL 2D Array of DBL

click here for general information on data types.

Return value

The functions return a value with the same data type as x.

Example

x = ln(-1);  // x is NaN
_isnan(x);   // returns 1
_finite(x);  // returns 0

x = ln(0);   // x is -Inf
_isnan(x);   // returns 0
_finite(x);  // returns 0

x = 1;
_isnan(x);   // returns 0
_finite(x);  // returns 1

getexp

The function computes a mantissa and an exponent of a real number, and returns the exponent.

Implementation: FastFunc.

Syntax

getexp(x)

Description

The function breaks down x into a mantissa (m) and an exponent (n), such that

   x = m * pow2(n)

where n is the integer, and the absolute value of m is greater than or equal to 0.5 and less than 1.0.

The function returns the exponent (n).

Parameters

The function can operate on scalars and arrays. The result is produced according to the polymorphism rules. Formally, x can have the following data types:

DBL Number 1D Array of DBL 2D Array of DBL

click here for general information on data types.

Return value

The function returns a value with the same data type as x.

Example

getman(-3.6);  // returns -0.9
getexp(-3.6);  // returns 2
getman(0.3);   // returns 0.6
getexp(0.3);   // returns -1

ldexp

The function computes a real number from the mantissa and exponent.

Implementation: FastFunc.

Syntax

ldexp(x,y)

Description

The function returns a value that is computed as

x * pow2( int(y) ).

Parameters

The function can operate on scalars, arrays, and combinations thereof. The result is produced according to the polymorphism rules. Formally, x and y can have the following data types:

DBL Number 1D Array of DBL 2D Array of DBL

click here for general information on data types.

Return value

The data type of the return value is determined by the polymorphism rules for function with two arguments.

Example

x = ldexp(3,4);  // x is equal 48

Comment

ldexp(getman(x),getexp(x)) is equal to x
