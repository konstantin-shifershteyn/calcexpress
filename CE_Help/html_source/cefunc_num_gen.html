i32b, i32s, u32b, u32s

The functions convert values to 32-bit integers.

Implementation: FastFunc.

Syntax

i32b(x)
i32s(x)
u32b(x)
u32s(x)

Description

i32b function coerces x to a signed 32-bit integer representation by applying Bit-keeping Conversion, and returns the result of the conversion. The result is an integer number in the range of -231 to 231-1 (or -2147483648 to 2147483647).

i32s function coerces x to a signed 32-bit integer representation by applying Saturating Conversion, and returns the result of the conversion. The result is an integer number in the range of -231 to 231-1 (or -2147483648 to 2147483647).

u32b function coerces x to an unsigned 32-bit integer representation by applying Bit-keeping Conversion for unsigned integers, and returns the result of the conversion. The result is an integer number in the range of 0 to 232-1 (or 0 to 4294967295).

u32s function coerces x to an unsigned 32-bit integer representation by applying Saturating Conversion for unsigned integers, and returns the result of the conversion. The result is an integer number in the range of 0 to 232-1 (or 0 to 4294967295).

NOTE: All functions return an undefined value for NaN inputs. In addition, the result of Bit-keeping Conversion is also undefined for Inf and -Inf values.

Parameters

The function can operate on scalars and arrays. The result is produced according to the polymorphism rules. Formally, x can have the following data types:

DBL Number 1D Array of DBL 2D Array of DBL

click here for general information on data types.

Return value

The data type of the return value is determined by the polymorphism rules for functions with one argument.

Example

//--- a positive in-range value
i32s(3.14);          /* returns 3 */
i32b(3.14);          /* returns 3 */
u32s(3.14);          /* returns 3 */
u32b(3.14);          /* returns 3 */
//--- a negative value
i32s(-1);            /* returns -1 */
i32b(-1);            /* returns -1 */
u32s(-1);            /* returns 0 (Clamped to floor) */
u32b(-1);            /* returns 4294967295 (Wrapped via two's complement) */
//--- a positive out-of-range value
i32s(5000000005.5);  /* returns 2147483647 (Clamped to ceiling) */
i32b(5000000005.5);  /* returns 705032709 (Upper bits discarded) */
u32s(5000000005.5);  /* returns 4294967295 (Clamped to ceiling) */
u32b(5000000005.5);  /* returns 705032709 (Upper bits discarded) */
//--- a negative out-of-range value
i32s(-5000000005.5); /* returns -2147483648 (Clamped to floor) */
i32b(-5000000005.5); /* returns -705032709 (Upper bits discarded, evaluated as signed) */
u32s(-5000000005.5); /* returns 0 (Clamped to floor) */
u32b(-5000000005.5); /* returns 3589934587 (Upper bits discarded, evaluated as unsigned) */

land

The function computes the logical AND for all input values (aggregate logical AND).

Implementation: FastFunc.

Syntax

land(x1 ,x2 ... ,xn)

Description

The function can operate on an arbitrary non-zero number of arguments, considering all actual parameters as a single aggregate data set.

The function returns 1 (TRUE) if all elements of the aggregate data set are TRUE; i.e. if each element coerced to an integer is not equal to zero. Otherwise it returns 0 (FALSE).

The function coerces its inputs to a 32-bit integer representation by applying Bit-keeping Conversion.

Parameters

The function can operate on scalars, arrays, and any combinations thereof. Formally, it operates on the following data types:

DBL Number 1D Array of DBL 2D Array of DBL

click here for general information on data types.

Return value

The function returns a value of the DBL Number data type.

Comment

The function is useful for performing aggregate comparisons. For more information, see the description of CalcExpress Relational Operators.

Example

v = vector(1,3,5,7); //v is array {1,3,5,7}
land( v > 0 );
/* returns 1 because all elements of v are greater than 0 */
land( v >= 5 );
/* returns 0 because there are elements that are less than 5 */
land( (v > 0), (v < 10) );
/* returns 1 because all elements of v are greater than 0, and are less then l0 */
land( (v > 0), (v < 10), v[0] == v[1] );
/* returns 0 because v[0] is not equal to v[1] */

The function returns 0 (FALSE) if all elements of the aggregate data set are FALSE; i.e. if each element coerced to integer is equal to zero. Otherwise it returns 1 (TRUE).

Parameters

The function can operate on scalars, arrays, and any combinations thereof. Formally, it works on the following data types:

DBL Number 1D Array of DBL 2D Array of DBL

click here for general information on data types.

Return value

Comment

The function is useful for performing aggregate comparisons. For more information, see the description of CalcExpress Relational Operators.

Example

v = vector(1,3,5,7); //v is array {1,3,5,7}

/* returns 0 because all elements of v are greater than 0 */

/* returns 1 because there are elements that are greater than 4 */

Implementation: FastFunc.

Syntax

Description

The function can operate on an arbitrary non-zero number of arguments; herewith, it considers all the actual parameters as a single aggregate data set.

The function returns the maximum value in the aggregate data set.

Parameters

The function can operate on scalars, arrays, and any combinations thereof. Formally, it works on the following data types:

DBL Number 1D Array of DBL 2D Array of DBL

click here for general information on data types.

Return value

The function returns a value of the DBL Number data type.

Comment

If you need to find an index of the maximum element in an array, use the search function. See example below.

Example

x = 5;
y = 0.1;
v = vector(-1,7,3,5); //v is array {-1,7,3,5}
max(x,y);             //returns 5
max(v);               //returns 7
max(4, x, v*y);       //returns 5 (x value)
search(v, max(v));
/* returns 1 that is index of maximum value (7) in v */

mean

The function computes the mean (average) of argument values.

Implementation: FastFunc, FuncVI.

Syntax

mean(x1 ,x2 ... ,xn)

Description

The function can operate on an arbitrary non-zero number of arguments; herewith, it considers all the actual parameters as a single aggregate data set.

The function returns the mean of all the elements in the aggregate data set. The mean is computed using the formula sum(X)/N, where X is the aggregate data set, and N is the number of elements in the aggregate data set.

Parameters

The function can operate on scalars, arrays, and any combinations thereof. Formally, it works on the following data types:

DBL Number 1D Array of DBL 2D Array of DBL
CDB Number 1D Array of CDB 2D Array of CDB

click here for general information on data types.

Return value

The function returns a scalar value. The value has the DBL Number data type if all of the actual parameters have a real representation (DBL). If there is a parameter with a complex representation (CDB), the return value has the CDB Number data type.

Example

x = 5;
v = vector(10,20,30); //v is array {10,20,30}
mean(v);       //returns 20
mean(x,6,7);   //returns 6
mean(v,x,15);  //returns 16

random

The function generates random numbers.

Implementation: FastFunc, FuncVI.

Syntax

random(x ,y)

Description

The function returns a random number computed using the formula:

   x * RND + y ,

where RND is a uniformly distributed random number in the range 0 to 1.

Parameters

Both x and y are optional arguments that can be omitted in a function call. By default, x is equal to 1, and y is equal to 0.

The function can operate on scalars, arrays, and combination thereof. The result is produced according to the polymorphism rules. Formally, x and y can have the following data types:

DBL Number 1D Array of DBL 2D Array of DBL

click here for general information on data types.

Return value

The data type of the return value is determined by the polymorphism rules for function with two arguments.

Comment

If the function returns an array, it generates random number for every element of the array.
