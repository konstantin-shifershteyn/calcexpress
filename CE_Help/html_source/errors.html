  CalcExpress and CSE VI error codes

Top-level CalcExpress and CSE VIs return error information in a standard error out cluster. If an error occurs, the status member of the cluster is set to TRUE, the code member contains an error code, and the source member contains both the location where the error occurred and the error description. CalcExpress and CSE specific error codes are listed below. Note that code can indicate a LabVIEW memory manager error code if a memory error occurs. In addition, code can contain a user-defined code if you specify it in your FuncVI using Exp - Error handler.vi.

7100Invalid CSE RefNum.
7101Invalid CalcExpress Instance reference.
7102Syntax error. An error was detected during script parsing.
7103Runtime Error. An error occurred during script execution.
7104Execution Aborted. An abort signal was received during script execution.
7105Generic Error. In the current version, this error can only occur if the evaluation session time has expired.
7106FuncVI not found. A called function is not embedded, and the respective FuncVI could not be located.
7107Invalid FuncVI. A called FuncVI is invalid or is in an invalid state.

 

 

 

  VarMan VI error codes

VarMan VIs return error information in a standard error out cluster. If an error occurs, the status member of the cluster is set to TRUE, the code member contains one of the codes listed below, and the source member contains both the location where the error occurred and the error description.

7000Unknown VarMan error.
7001Invalid variable type. The actual type of the specified variable differs from either the expected or the explicitly specified type.
7002Variable not found. A variable with the specified name does not exist in the given Variable Context.
7003Variable already exists. The specified name is not unique. The target Variable Context already contains a variable with this name.
7004 The specified Variable Context handle is invalid.
7005Input error. Typically, this error is never returned by top-level VarMan VIs.
7006Invalid data format. VarMan encountered a mismatch between the variable data type and the format of the data stored within it. This typically occurs due to the misuse of low-level VarMan VIs or an incorrect value format returned by a FuncVI
7007No history attached. The specified variable does not have a history attached.
7008History already attached. A history configuration cannot be created because the specified variable already has a history attached.
7009Invalid history parameters. The configuration parameters provided to create the variable history are invalid (e.g., the history length is less than or equal to zero).
7010Wrong variable name. The specified name string is invalid for variable creation.
7011Wrong alias name. The specified name string is invalid for creating or renaming an alias.
7012Non-unique alias. The alias name is already in use. Another alias already uses the specified name.
7013Alias not found. The specified alias could not be located.
7014No alias associated. The specified variable does not have an associated alias.
7015Alias already associated. The specified variable already has an associated alias.
7016Wrong context name. The specified name string is invalid for assignment to a Variable Context.
7017Non-unique context name. The context name is already in use. Another Variable Context is already assigned the specified name.
7018Context name not found. A Variable Context with the specified name was not found.
7019Invalid parameter. A generic error caused by invalid parameters passed to VarMan Engine. This code is typically never returned by top-level VarMan VIs.
7020Generic error. A miscellaneous error occurred. Potential causes include insufficient system resources, exceeding the maximum allowed number of open Variable Contexts, or an expired evaluation/demo session.
7021Memory full. Insufficient system memory to complete the requested operation.
7022Unrecognized LabVIEW manager error. The LabVIEW manager returned an error that could not be handled.

 

 

 

  VarMan Engine error codes

To signal the completion status of a requested operation, the VarMan Engine returns a numeric error code. Many VarMan VIs feature a dedicated numeric indicator, typically named err code, to output this status directly. Note that VarMan VIs also provide a standard error out cluster, whose error codes differ from the VarMan Engine error codes; see the VarMan VI error codes topic for information on them.

VarMan Engine returns the following error codes:

0No error. The operation completed successfully.
1Invalid variable type. The actual type of the specified variable differs from either the expected or the explicitly specified type.
2Variable not found. A variable with the specified name does not exist in the given Variable Context.
3Variable already exists. The specified name is not unique. The target Variable Context already contains a variable with this name.
4 The specified Variable Context handle is invalid.
5Input error. Typically, this error is never returned by top-level VarMan VIs.
6Invalid data format. VarMan encountered a mismatch between the variable data type and the format of the data stored within it. This typically occurs due to the misuse of low-level VarMan VIs or an incorrect value format returned by a FuncVI
7No history attached. The specified variable does not have a history attached.
8History already attached. A history configuration cannot be created because the specified variable already has a history attached.
9Invalid history parameters. The configuration parameters provided to create the variable history are invalid (e.g., the history length is less than or equal to zero).
10Wrong variable name. The specified name string is invalid for variable creation.
11Wrong alias name. The specified name string is invalid for creating or renaming an alias.
12Non-unique alias. The alias name is already in use. Another alias already uses the specified name.
13Alias not found. The specified alias could not be located.
14No alias associated. The specified variable does not have an associated alias.
15Alias already associated. The specified variable already has an associated alias.
16Wrong context name. The specified name string is invalid for assignment to a Variable Context.
17Non-unique context name. The context name is already in use. Another Variable Context is already assigned the specified name.
18Context name not found. A Variable Context with the specified name was not found.
19Invalid parameter. A generic error caused by invalid parameters passed to VarMan Engine. This code is typically never returned by top-level VarMan VIs.
20Generic error. A miscellaneous error occurred. Potential causes include insufficient system resources, exceeding the maximum allowed number of open Variable Contexts, or an expired evaluation/demo session.
21Memory full. Insufficient system memory to complete the requested operation.
22Unrecognized LabVIEW manager error. The LabVIEW manager returned an error that could not be handled.
