CSE Script syntax

CSE processes scripts with a syntax that can look like that of the C programming language. A script consists of statements that perform calculations and control the flow of script execution. Statements are executed sequentially, one after another, unless control flow statements alter this order.

In order to document a script, use comments that have the same syntax as CalcExpress Comments.

 

Statements

if statement break statement
for statement continue statement
while statement goto statement and labels
dowhile statement return statement
Expression statement
Compound statement
Null statement

 

Statements Overview

CSE statements consist of keywords, expressions, and other statements.

  • A keyword identifies the type of statement and is an integral part of it.
  • An expression is a combination of operands, operators, and function calls that can be recognized and processed by the expression evaluator (CalcExpress). An expression has to comply with the CalcExpress expression syntax.
  • Some statements require other statement(s) to complete them. A statement that forms a component of another statement is called the body of the enclosing statement.

All statements, except for the compound statement, must end with a semicolon ( ; ). The compound statement is delimited by braces ( { } ). It groups multiple statements (including other compound statements) and represents them as a single statement. The compound statement is typically used as a statement's body.

A statement that contains only an expression is the expression statement. Depending on the parsing parameters, sequences of expression statements can be grouped together or treated individually to be passed to CalcExpress for evaluation.

Any statement can begin with a label that identifies it. A label consists of a label name and a colon ( : ) following it. Only the goto statement recognizes labels.

CSE Script syntax:  'if'  statement

The if statement controls conditional execution. It allows executing certain parts of a script depending on the value of a conditional expression. There are two syntax forms for the if statement.

Syntax

if ( expression ) statement1
if ( expression ) statement1 else  statement2

In both forms, expression is evaluated first. The expression can be any valid CalcExpress expression that evaluates to a numeric scalar. The expression is false if its value, when coerced to an integer (int32) by applying Saturating Conversion, is equal to zero; otherwise, it is true.

The statement1 is executed if expression is true. If expression is false, statement1 is ignored and, if the second form is used, statement2 is executed. With both forms, control then passes to the statement following the if statement, unless an executed statement contains break, continue, goto, or return.

if (x < 1)
   y = 0;       /* y = 0 if x less than 1 */
else
   y = x-1;     /* otherwise y = x-1 */

Both statement1 and statement2 are any valid statements. It is especially useful to use a compound statement that groups multiple statements into a single statement.

if (x < 1) {
   x += 1; y = 0;     /* statements are executed if x<1 */
}
else {
   x -= 1; y = x;     /* statements are executed if x>=1 */
}

When an else is encountered in nested if statements, it is associated with the closest if that does not have a corresponding else. If this rule needs to be changed, use braces ( { } ) to group statements into a compound statement to clarify your intention.

if (x > 0) {       /* line 1 */
   if (x > y)      /* line 2 */
      x = y;
   else            /* corresponds to the if in line 2 */
      y = x;
}
if (z > x) {       /* line 7 */
   if (z > y)      /* line 8 */
      z = y;
}
else               /* corresponds to the if in line 7 */
   z = x;

CSE Script syntax:  'for'  statement

The for statement repeats the execution of a block of script until a conditional expression becomes false. Furthermore, optional expressions within the for statement allow initializing and modifying values during execution. The for statement is useful if there is a need to repeat a block of code a specified number of times.

Syntax

for ( init-exp ; cond-exp ; loop-exp ) statement

The init-exp is an optional initialization expression. If present, it is evaluated once when the for statement begins. The init-exp can be any valid CalcExpress expression.

The cond-exp is an optional conditional expression. If present, it is evaluated before each iteration. If the cond-exp is false, control passes to a statement following the for statement. If the cond-exp is true, the statement (loop-body) is executed. Then, the loop-exp, if any, is evaluated. The next iteration then begins with the evaluation of the cond-exp.

The cond-exp is any valid CalcExpress expression that evaluates to a numeric scalar. The cond-exp is false if its value, when coerced to an integer (int32) by applying Saturating Conversion, is equal to zero; otherwise, it is true.

If the cond-exp is omitted, it is assumed to be true. In this case, an infinite loop is created that can only be terminated with break, goto, or return statements.

The loop-exp is an optional loop expression. If present, it is evaluated at the end of each iteration, after statement has been executed. The loop-exp can be any valid CalcExpress expression.

The statement, also called loop-body, is any valid statement. To execute more than one statement within loop-body, use a compound statement that groups multiple statements into a single statement.

The execution order of the for statement can be changed with break, continue, goto, or return. These statements determine subsequent behavior if they are encountered during execution. The break statement immediately terminates the for loop, and the loop-exp is not evaluated. The continue statement terminates the current iteration of the loop (i.e., it skips the rest of the loop-body), evaluates the loop-exp, and transitions to the next iteration.

Example

/* Compute both factorial of X and sum of numbers from 0 to X for all positive X
*/
for( i=1, sum=0, fact=1; i <= X; i++ ) {
   fact *= i;
   sum  += i;
}

CSE Script syntax:  'while'  statement

The while statement repeats the execution of a block of script until a conditional expression becomes false.

Syntax

while ( expression ) statement

The expression is any valid CalcExpress expression that evaluates to a numeric scalar. The expression is false if its value, when coerced to an integer (int32) by applying Saturating Conversion, is equal to zero; otherwise, it is true.

The statement, also called loop-body, is any valid statement. To execute more than one statement within loop-body, use a compound statement that groups multiple statements into a single statement.

The while statement executes as follows:
1.   The expression is evaluated.
2.   If the expression is false, control passes to the statement following the while statement.
3.   If the expression is true, the statement (loop-body) is executed. The execution is then repeated at step 1.

Note that the statement is never executed if expression is initially false.

The execution order of the while statement can be changed with break, continue, goto, or return. These statements determine subsequent behavior if they are encountered during execution. The continue statement skips the rest of the loop-body and starts the next iteration by evaluating the conditional expression (step 1).

Example

cnt = 0;
/*
while x is greater than 1, multiply it by random number in range 0 to 1
*/
while ( x >= 1) {
   x *= random();
   cnt++;
}

CSE Script syntax:  'dowhile'  statement

The dowhile statement executes a block of script and repeats its execution until a conditional expression becomes false.

Syntax

dowhile ( expression ) statement

The expression is any valid CalcExpress expression that evaluates to a numeric scalar. The expression is false if its value, when coerced to an integer (int32) by applying Saturating Conversion, is equal to zero; otherwise, it is true.

The statement, also called loop-body, is any valid statement. To execute more than one statement within loop-body, use a compound statement that groups multiple statements into a single statement.

The dowhile statement executes as follows:
1. The statement (loop-body) is executed.
2. Next, the expression is evaluated.
3. If the expression is true, the process is repeated, beginning with step 1. If the expression is false, the dowhile statement terminates, and control passes to the statement following the dowhile statement.

Note that expression is evaluated after the statement is executed. Therefore, the statement is always executed at least once.

The execution order of the dowhile statement can be changed with break, continue, goto, or return. These statements determine subsequent behavior if they are encountered during execution. The continue statement skips the rest of the loop-body and starts the next iteration by evaluating the conditional expression (step 2).

Example

/*
repeats until rms(x) becomes less than a threshold
*/
dowhile ( rms(x) >= threshold) {
   params = GetNewParams();
   x = GetData(params);
}

CSE Script syntax:  'break'  statement

The break statement terminates the execution of the nearest enclosing for, while, or dowhile statement in the body of which it is encountered. Control passes to the statement that follows the terminated statement.

Syntax

break ;

Within nested statements, the break statement terminates only the statement that immediately encloses it. To terminate deeply nested loops, it is convenient to use the goto statement.

If the break statement terminates the for loop, the loop expression (loop-exp) of the for statement is not evaluated.

To better understand the behavior of the break statement, let's consider the following examples.

while(...) {
   . . .
   break;
   . . .
   goto out;
   . . .
}
out: ; 		for(...) {
   . . .
   break;
   . . .
   goto out;
   . . .
}
out: ;

In these examples, both the break statement and the goto out statement cause the same effect.

CSE Script syntax:  'continue'  statement

The continue statement terminates the current iteration and begins the next iteration of the nearest enclosing for, while, or dowhile statement in the body of which it is encountered. If the continue statement is executed, the rest of the enclosing statement body is bypassed.

Syntax

continue ;

For the for, while, and dowhile statements, the next iteration starts with evaluating a conditional expression and determining whether to execute a statement body. If the continue statement is executed inside a for loop, the loop expression (loop-exp) of the for statement is evaluated before the next iteration starts.

To better understand the behavior of the continue statement, let's consider the following examples.

while(...) {
   . . .
   continue;
   . . .
   goto contin;
   . . .
contin: ;
} 		for(...) {
   . . .
   continue;
   . . .
   goto contin;
   . . .
contin: ;
}

In these examples, both the continue statement and the goto contin statement cause the same effect.

CSE Script syntax:  'return'  statement

The return statement immediately ends the execution of a script. Optionally, it can return the value of its expression if one is specified. The return value is available as an output of the CSE - Execute Parsed Script.vi.

Syntax

return expression ;

The optional expression specifies the value to be returned. The expression can be any valid CalcExpress expression that evaluates to a value of the DBL Number data type. If the expression is omitted, the return value is zero.

If a script finishes without executing the return statement, such as when the end of the script is reached, the return value is zero.

CSE Script syntax:  'goto' statement and labels

The goto statement transfers control to a statement marked with the given label. The label must reside in the processed script.

Syntax

goto identifier ;

The identifier is the name of the label to transfer control to.

 

Labels

A label can be placed before any statement. A label is an identifier followed by the colon ( : ).

Syntax

identifier : statement

The identifier is a label name. Every label must have a unique name; it is impossible to redeclare a label.

Labels are only recognized by the goto statement; they do not have any influence on the execution of labeled statements.

A label requires a statement that follows it. Use the null statement if it is necessary to place a label without regard to any statement, such as at the end of a script or at the end of a compound statement.

CSE Script syntax:  null statement

The null statement is a statement containing only a semicolon ( ; ). It can appear wherever a statement is expected. Nothing is done when the null statement is executed. The purpose of the null statement is to fulfill syntax requirements in situations where a statement is required but no action needs to be taken.

Syntax

;

It is useful to use the null statement when it is necessary to place a label at the end of compound statement or at the end of a script.

You can also use the null statement to declare an empty body for the if, for, while, and dowhile statements.

CSE Script syntax:  expression statement

The expression statement contains a CalcExpress expression that needs to be evaluated. It must end with a semicolon ( ; ), which serves as the statement terminator.

Syntax

expression ;

The expression can be any valid CalcExpress expression. There are no restrictions on the data type of an expression.

Expression statements do not affect the order of statement execution. After an expression statement has been executed, control passes to the next statement in the script.

Example

w = rad(45), t = 0.7, f = 10;            /*it's one statement*/
x = nvecifn(0, pi(2), 1000);
y = exp(-t*x) * sin(f*x+w);
XYGraph(0, x, y,"Damping oscillation");  /*function shows a graph*/

CSE Script syntax:  compound statement

The compound statement (also called a block) groups multiple statements into a single statement. It is typically used to execute multiple statements in the body of another statement, such as the if, for, while, and dowhile statements.

Syntax

{ list-of-statements }

The list-of-statements is a set of any valid statements (including the compound statements).

 

Example

/*
If cmd equals "erf" all statements inside the compound statement are executed in the order.
*/
if (cmd == "erf") {
   x0 = 0, dx = 0.1;
   x  = nvecifs(x0, 5, dx);
   y  = erf(x);
   WFGraph(0, y, x0, dx, "y = erf(x)");
}
