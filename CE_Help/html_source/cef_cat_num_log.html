The functions listed in this section have the polymorphism capability described in the Polymorphism for Numeric functions topic. A description of each function includes a list of data types that the function can operate on.

Logarithmic functions

ln(x) natural logarithm of x (logarithm to the base e) + +
log(x,y) logarithm of y to the base x + +
log2(x) logarithm of x to the base 2 + +
log10(x) logarithm of x to the base 10 + +

Exponential functions

exp(x) e raised to the x power (exponential function) + +
pow(x,y) x raised to the y power + +
pow2(x) 2 raised to the x power + +
pow10(x) 10 raised to the x power + +

Relevant functions

e(x) returns e or the argument multiplied by e + +
