viAbort

The function stops execution of the specified Virtual Instrument.

Implementation: FuncVI.

Syntax

viAbort(viName ,CloseFP)

Description

The function opens a VI reference to the VI specified by viName and aborts the execution of it. If requested, the function also closes the VI's Front Panel.

To specify the target VI, you can pass either the name or the full path of the VI to the viName parameter. Note that the function closes the reference to the VI before it returns. Thus, the VI could be implicitly unloaded when the function returns if its Front Panel is closed and there are no open references to it.

The function assigns an error code returned by the used LabVIEW functions to the rtErrorCode variable. You can evaluate it using the errno function. If this function completes successfully, the error code is zero.

Parameters

data type description
viName String Required parameter specifies either the name or the full path of the target VI.
CloseFP DBL Number Optional parameter. If its value coerced to an integer is non-zero, the function closes the VI's Front Panel. By default, it equals to zero.

Return value

The function returns an error status that has the same value as the rtErrorCode variable. If no error occured, the function returns zero.

The Return value has the DBL Number data type.

viCtrlGet

The function allows obtaining values of Front Panel Controls and Indicators of the specified Virtual Instrument.

Implementation: FuncVI.

Syntax

viCtrlGet(viName,ctrlName1,var1 ,ctrlName2,var2 ...)

Description

The function opens a VI reference to the VI specified by viName and saves the values of its Controls or Indicators, specified by the ctrlName parameters, at the respective var variables.

To specify the target VI, you can pass either the name or the full path of the VI to the viName parameter. If you provide a VI name, the VI must already be in memory. If you provide a VI path, the function loads the VI into memory unless it is already in memory. Note that the function closes the reference to the VI before it returns. Thus, the VI could be implicitly unloaded when the function returns if it was not in memory before the function call.

The function saves a Control value at a var variable if they have compatible data types. If the function cannot convert a value of any Control to the data type of the respective variable, it assigns an error code to the rtErrorCode variable. The following rules of compatibility are used:

  • a control and a variable must have the same dimensionality; i.e.:
    • if a variable is an array, the respective control must be an array with the same number of dimensions.
    • if a variable is either a numeric scalar or a string, the respective control must be a simple numeric or string control; it may not be an array, cluster, waveform, and so on.
  • a control and a variable must have compatible representations:
    • CalcExpress numeric values (DBL and CDB) are compatible to LabVIEW numeric and boolean values.
    • CalcExpress strings are compatible to LabVIEW strings and paths.

The function assigns an error code returned by the used LabVIEW functions to the rtErrorCode variable. You can evaluate it using the errno function. If this function completes successfully, the error code is zero.

Parameters

data type description
viName String Required parameter specifies either the name or the full path of the target VI.
ctrlName String Parameters specify the names of Controls or Indicators on the VI's Front Panel. Control names are case-sensitive.
The function can handle one or more ctrlName parameters, provided that each one has a corresponding var parameter.
var Identifier
(variable name)		 Parameters specify the existing variables of any predefined data type. The function saves VI Control values at these variables. If any variable doesn't exist, an error occurs. The number of var parameters must be the same as the number of ctrlName parameters. At least one var parameter is required.

Return value

The function returns an error status that has the same value as the rtErrorCode variable. If no error occured, the function returns zero.

The Return value has the DBL Number data type.

VI Control functions, File functions.

viOpenFP

The function opens or closes Front Panel window of the specified Virtual Instrument.

Implementation: FuncVI.

Syntax

viOpenFP(viName ,open)

Description

The function opens a VI reference to the VI specified by viName and either opens or closes the VI's Front Panel, depending on the value of the open parameter.

To specify the target VI, you can pass either the name or the full path of the VI to the viName parameter. If you provide a VI name, the VI must already be in memory. If you provide a VI path, the function loads the VI into memory unless it is already in memory. Note that the function closes the reference to the VI before it returns. Parameters

data type description
viName String Required parameter specifies either the name or the full path of the target VI.
open DBL Number Optional parameter. If its value coerced to an integer is non-zero, the function opens the Front Panel window of the target VI and brings it to the front. Otherwise, the function closes the Front Panel window. By default, it equals to 1.

Return value

The function returns an error status that has the same value as the rtErrorCode variable. If no error occured, the function returns zero.

viRun

The function starts execution of the specified Virtual Instrument.

Implementation: FuncVI.

Syntax

viRun(viName ,OpenFP ,ctrlName1,x1 ,ctrlName2,x2 ...)

Description

The function opens a VI reference to the VI specified by viName and runs it. If the function call contains the ctrlName and x parameters, the function assigns the values of x parameters to the VI's Controls specified by the respective ctrlName parameters before starting the VI. If requested, the function opens the Front Panel of the VI just after starting it.

If the specified VI is not in the idle state (already running or corrupt), the function does not change the Control values and the Front Panel state of the VI. Instead, it assigns an error code to the rtErrorCode variable.

To specify the target VI, you can pass either the name or the full path of the VI to the viName parameter. If you provide a VI name, the VI must already be in memory. If you provide a VI path, the function loads the VI into memory unless it is already in memory. Note that the function closes the reference to the VI before it returns. Thus, the VI could be implicitly unloaded when the function returns if its Front Panel is closed and there are no open references to it. If a called VI needs to run with the closed Front Panel, it should open a VI reference to itself in order to stay in memory.

The function assigns an x value to a Control if they have compatible data types. If the function cannot convert an x value to the data type of the respective Control, it assigns an error code to the rtErrorCode variable. The following rules of compatibility are used:

  • a control and an x value must have the same dimensionality; i.e.:
    • if an x value is an array, the respective control must be an array with the same number of dimensions.
    • if an x value is either a numeric scalar or a string, the respective control must be a simple numeric or string control; it may not be an array, cluster, waveform, and so on.
  • a control and an x value must have compatible representations:
    • CalcExpress numeric values (DBL and CDB) are compatible to LabVIEW numeric and boolean values.
    • CalcExpress strings are compatible to LabVIEW strings and paths.

The function assigns an error code returned by the used LabVIEW functions to the rtErrorCode variable. You can evaluate it using the errno function. If this function completes successfully, the error code is zero.

Parameters

data type description
viName String Required parameter specifies either the name or the full path of the target VI.
OpenFP DBL Number Optional parameter. If its value coerced to an integer is non-zero, the function opens the VI's Front Panel window and brings it to the front. By default, it is equal to 1.
ctrlName String Optional parameters specify the names of Controls or Indicators on the VI's Front Panel. Control names are case-sensitive.
The function can handle zero or more ctrlName parameters, provided that each one has a corresponding x parameter.
x any predefined Optional parameters specify values to be assigned to the respective ctrlName controls. Number of x parameters must be the same as the number of ctrlName parameters.

Return value

The function returns an error status that has the same value as the rtErrorCode variable. If no error occured, the function returns zero.

The Return value has the DBL Number data type.

viState

The function returns a state of the specified Virtual Instrument.

Implementation: FuncVI.

Syntax

viState(viName ,mode)

Description

The function opens a VI reference to the VI specified by viName and returns the execution state or the front panel state of the VI, depending on the value of the mode parameter.

To specify the desired VI, you can pass either a name or a path of the VI to viName parameter. If you pass a VI name, the VI must already be in memory. If you pass a VI path, the function attempts to load it into memory unless it is already in memory. Note that the function closes a reference to the VI before it returns. Thus, the VI can be implicitly unloaded when the function returns if it was not in memory before a call of the function.

The optional parameter mode defines what state the function should return.

mode equals 0 (default). The function returns the VI execution state whose value is equal to the VI's Execution.State property. According to the LabVIEW documentation, the return value can be one of the following:
0 - Bad. The VI is not executable.
1 - Idle. The VI is not running but it is ready to be run.
2 - Running top level. The VI is running as the top-level VI in an hierarchy.
3 - Running. The VI is reserved for execution by at least one active top-level VI.

mode equals 1. The function returns 1 (TRUE) if the VI's Front Panel is visible (normal or maximized). Otherwise, it returns 0 (FALSE).

mode equals 2. The function returns the VI Front Panel state whose value is equal to the VI's Front Panel.State property. According to the LabVIEW documentation, the return value can be one of the following:
0 - Invalid.
1 - Standard.
2 - Closed.
3 - Hidden.
4 - Minimized.
5 - Maximized.

The function assigns an error code returned by the used LabVIEW functions to the rtErrorCode variable. You can evaluate it using the errno function. If this function completes successfully, the error code is zero.

Parameters

data type description
viName String Required parameter specifies either the name or the full path of the target VI.
mode DBL Number Optional parameter specifies the kind of VI state that the function should return. The valid values are 0, 1 and 2. By default, it equals zero.

Return value

The function returns an integer value with the DBL Number data type, which indicates the requested state.
