CSE Script Control functions

The functions listed in this section can be executed in a CSE script only. They provide support to call a script from a script or execute a script in framework of another script. All these functions are implemented as FuncVIs.

Click on a function name below for detailed information on the function.

function quick info
abort aborts execution of CalcExpress and CSE scripts
Call calls a CSE script from a CSE script.
CallLevel returns nesting level of the current CSE script in its call chain.
Exec executes a CSE script in framework of another CSE script.
ScriptPath returns a file path of a running CSE script.
SearchPath adds or returns paths to search CSE script files.

Relevant functions

vwrid reads or writes the Writer ID for the script instance.
