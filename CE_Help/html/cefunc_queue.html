QueueCreate

The function creates a queue with the specified name.

Implementation: FuncVI.

Syntax

QueueCreate(name ,size)

Description

The function creates a new queue with the specified name unless a queue with the same name already exists. The function works with LabVIEW queues that handle string data.

The function assigns an error code returned by the used LabVIEW functions to the rtErrorCode variable. You can evaluate it using the errno function. If this function completes successfully, the error code is zero.

Parameters

data type description
name String required parameter that specifies the name of the queue.
size DBL Number optional parameter that specifies the maximum number of elements the queue can hold. The function coerces this parameter to an integer. If size is less than or equal to zero, the queue size is unlimited. By default, size equals -1.

Return value

The function returns 1 (TRUE) if a new queue is created; otherwise, it returns 0 (FALSE).

The return value has the DBL Number data type.

Example

/* It's example of CSE script */
qName = "QUEUE";
if (QueueCreate(qName)) {
  MsgBox("New queue is created");
}
else {
  if (errno())
     lvErrorMessage("Create Queue Error");
  else
     MsgBox("Queue already exists");
}

QueueGet

The function extracts an element from the specified queue.

Implementation: FuncVI.

Syntax

QueueGet(name ,tmo)

Description

The function removes an element from the front of the queue specified by the name parameter. If the queue is empty, the function waits until at least one queue element becomes available or the specified timeout expires. If the function finishes by timeout, it assigns the error code 56 to the rtErrorCode variable. Otherwise, the function returns the removed element. The function works with LabVIEW queues that handle string data.

The function assigns an error code returned by the used LabVIEW functions to the rtErrorCode variable. You can evaluate it using the errno function. If this function completes successfully, the error code is zero.

Parameters

data type description
name String required parameter that specifies the name of the queue.
tmo DBL Number optional parameter that specifies the timeout value in milliseconds.
To specify infinite timeout, set tmo to -1. By default, tmo equals 1000 milliseconds.

Return value

On success, the function returns the element removed from the queue name.

The return value has the String data type.

Example

/* It's example of CSE script */
qName = "QUEUE";
msg = QueueGet(qName, 0);
while(errno() == 56) {
  msg = QueueGet(qName, 1000);
}
if (errno() == 0)
  MsgBox("Queue element:\n", msg);
else
  lvErrorMessage("QueueGet Error");

QueuePut

The function inserts an element to the specified queue.

Implementation: FuncVI.

Syntax

QueuePut(name,msg ,tmo ,stk)

Description

The function inserts the element msg to the queue specified by the name parameter. If the queue is full, the function waits until at least one queue element becomes free or the specified timeout expires. If the function finishes by timeout, it assigns the error code 56 to the rtErrorCode variable. The function works with LabVIEW queues that handle string data.

The function assigns an error code returned by the used LabVIEW functions to the rtErrorCode variable. You can evaluate it using the errno function. If this function completes successfully, the error code is zero.

Parameters

data type description
name String required parameter that specifies the name of the queue.
msg String required parameter that specifies an element to be inserted to the queue.
tmo DBL Number optional parameter that specifies the timeout value in milliseconds. To specify infinite timeout, set tmo to -1. By default, tmo equals 1000 milliseconds.
stk DBL Number optional parameter. If its value coerced to an integer is non-zero (TRUE), the function adds msg to the front of the queue; otherwise, to the back. By default, stk is 0 (FALSE); i.e. msg is inserted at the end of the queue.

Return value

The function returns an error code that has the same value as the rtErrorCode variable. If no error occured, the function returns zero.

The return value has the DBL Number data type.

Example

/* It's example of CSE script */
qName = "QUEUE";
if (QueuePut(qName, "Message A")) {
   /* on an error */
   lvErrorMessage("Put to Queue Error");
}

QueueTest

The function tests if a queue with the given name exists.

Implementation: FuncVI.

Syntax

QueueTest(name)

Description

The function returns 1 (TRUE) if a queue with the specified name exists. Otherwise, it returns 0 (FALSE). The function works with LabVIEW queues that handle string data.

The function does not change the value of the rtErrorCode variable.

Parameters

data type description
name String required parameter that specifies the name of the queue.

Return value

The function returns 1 (TRUE) if a queue with the given name is found, or 0 (FALSE) otherwise.

The return value has the DBL Number data type.

Example

/* It's example of CSE script */
qName = "QUEUE";
if (QueueTest(qName))
   MsgBox("Queue exists");
else
   MsgBox("Queue doesn't exist");
