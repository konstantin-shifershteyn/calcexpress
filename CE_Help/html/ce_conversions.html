Conversion to Integer Values

Some CalcExpress operators and functions assume that the processed data is represented in a 32-bit integer format, while CalcExpress uses a floating-point data type as its basic type to store and operate on numeric data. Two conversion methods are utilized for implicitly converting floating-point values to a 32-bit integer representation, depending on the operational goal.

Saturating Conversion

(int32)(max(min(dbl,INT_MAX),INT_MIN))

A standard single-step numeric conversion. The goal of this conversion is to keep the value as close to the original magnitude as possible within the limits of the target data type. This conversion rounds floating-point values to the nearest integer and coerces (saturates) the result to the range of a signed 32-bit integer. This conversion is used for standard mathematical rounding and scaling, but it destroys the original low-order binary bit architecture on overflow, making it unsuitable for bitwise or logical operations.

  • This is the default conversion method that is applied in all cases unless explicitly noted otherwise.
  • When it is explicitly noted, the similar behavior applies to unsigned 32-bit destinations: (uInt32)dbl.

    • Bit-keeping Conversion

    (int32)(int64)dbl

    A multi-step numeric conversion designed to bypass standard saturating/clamping behavior. The goal of this conversion is to precisely preserve the lowest 32 bits of the integer part of a floating point value. By casting the large float to a 64-bit integer before narrowing it to a 32-bit integer, this operation safely discards the upper bits while keeping the targeted lower bit pattern intact. This conversion is used when performing bitwise and logical operators and functions, ensuring that mask operations, bit-shifting, or logic gates receive the correct underlying bit architecture.

  • When it is explicitly noted, the similar behavior applies to unsigned 32-bit destinations: (uInt32)(int64)dbl.

    • Explicit Conversions

    Whenever it is required to explicitly convert a floating-point value to an integer, the following built-in functions should be used:
    i32b, i32s, u32b, and u32s. They perform Saturating and Bit-keeping Conversions to signed and unsigned integers.
