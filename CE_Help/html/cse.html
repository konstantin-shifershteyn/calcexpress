CSE Overview

CSE (CalcExpress Script Engine) is a collection of VIs to execute textual scripts. CSE VIs are reentrant and multithreaded, enabling them to execute multiple scripts simultaneously and operate in parallel with other LabVIEW VIs. Beyond data processing, CSE can manage high-level application execution by directly interfacing with and controlling external VIs. This includes developing custom functions to be called from scripts as VIs (FuncVI), as well as utilizing ordinary VIs by running them directly from scripts and dynamically transferring data between active scripts and VIs using VI Control functions.

CSE is a superset of CalcExpress, enabling the use of all CalcExpress features while adding new capabilities to control script execution flow. Along with the sequential execution of script blocks, it provides repeated execution (loops), conditional execution (branches), and transfer of control (jumps). In addition, CSE Script Control functions can be used to call a script from within another script or execute a script within the context of a running script.

To evaluate expressions within CSE statements, CSE calls the CalcExpress kernel. Because both CSE and CalcExpress use a syntax similar to the C language, a CSE script structurally resembles a C program. See the Script Syntax topic for more information.

Like CalcExpress, CSE utilizes VarMan to operate on variables within a script. This architecture allows for specifying whether variables remain local to a single script or are shared across other VIs. Standard VarMan VIs are used to manage and manipulate these script variables externally.
