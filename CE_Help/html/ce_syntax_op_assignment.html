Assignment operator:  =

The Assignment operator assigns the value of its second (right-hand) operand to the first (left-hand) operand. The left-hand operand must be either a variable or an indexed-variable (see Subscript operator).

Syntax:

variable-expression = value-expression

Operand data types

The Assignment operator can operate on operands of all predefined data types, as well as user-defined data types. For more information, see comments below.

click here to get general information on data types.

Comments

Indexed-variable is an identifier (name of variable) followed by the Subscript operator. For example: x[1]

If the variable-expression denotes an existing variable (but not an indexed-variable), the value-expression must have the same data type as the variable.

If the variable-expression denotes an an indexed-variable, the value-expression must have a data type compatible with the variable-expression. An assignment is performed according to the rules described in the topics devoted to the Subscript operator. Note that the variable-expression must refer to an existing variable.

If the variable-expression is an identifier that does not correspond to any existing variable, a new variable can be created. In such a case, the new variable will have the same data type and value as the value-expression. You can forbid this feature by setting params.autoVar connector of a CalcExpress VI to FALSE when call it to process a script. Note that CalcExpress cannot create a variable if the variable-expression denotes an indexed-variable.

An assignment expression has the value and data type of its right-hand operand (value-expression).

Example

x = 4;
y1 = y2 = x+1;          /* both y1 and y2 are now 5 */

v1 = vector(1,2,3,4,5); /* v1 is 1D array {1,2,3,4,5} */
v2 = vector(7,8,9);     /* v2 is 1D array {7,8,9} */

v1[0] = 0;              /* v1 is now {0,2,3,4,5} */
v1[1:2] = 1;            /* v1 is now {0,1,1,4,5} */
v1[3:4] = v2;           /* v1 equals {0,1,1,7,8} now */

Compound Assignment operators

The Compound Assignment operators perform a relevant binary operation on the operands, and assign the result value to the left-hand operand. The left-hand operand must be either a variable or an indexed-variable (see Subscript operator).

Syntax:

variable-expression  **= expression (Exponentiation Assignment)
variable-expression  *= expression (Multiplication Assignment)
variable-expression  /= expression (Division Assignment)
variable-expression  %= expression (Remainder Assignment)
variable-expression  += expression (Addition Assignment)
variable-expression  -= expression (Subtraction Assignment)
variable-expression  >>= expression (Right-Shift Assignment)
variable-expression  <<= expression (Left-Shift Assignment)
variable-expression  &= expression (Bitwise-AND Assignment)
variable-expression  |= expression (Bitwise-OR Assignment)
variable-expression  ^= expression (Bitwise-XOR Assignment)

Operand data types

Compound Assignment operators can work on the same data types as the corresponding binary operators (click links above to get more information).

click here to get general information on data types.

Comments

The variable-expression must refer to an existing variable. Unlike the simple Assignment operator, Compound Assignment operators cannot create a new variable.

First, a Compound Assignment operator performs the same operation as the corresponding binary operator. Then, the result value is assigned to a variable denoted by the left-hand operand (variable-expression). An expression involving a Compound Assignment operator 'x op= y' can be understood as 'x = x op y'. For example, 'x+=y' expression is similar to 'x=x+y' expression.

A compound assignment expression has the value and data type of its left-hand operand (variable-expression) after assignment.

Example

x = 4;                  /* x is scalar equal to 4 */
v = vector(1,2,3,4,5);  /* v is 1D array {1,2,3,4,5} */
x += 1;                 /* x is now 5 */
v *= x;                 /* v is now {5,10,15,20,25} */
v[1:3] -= v[2];         /* v is now {5,-5, 0, 5,25} */
