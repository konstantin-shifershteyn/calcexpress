Synchronization functions

The functions listed in this section are implemented as FuncVIs. When you call any of these functions, CalcExpress calls LabVIEW Synchronization VIs to perform the task. Most functions assign an error code, which LabVIEW VIs return, to the rtErrorCode variable.

Click on a function name below for detailed information on the function.

function quick info

Notifications

NotifCancel(name) discards any existing notification
NotifCreate(name) creates a notifier with the specified name
NotifDestroy(name) destroys the specified notifier
NotifSend(name,msg) sends a message to the specified notifier
NotifTest(name) tests whether the specified notifier exists
NotifWait(name,tmo,ign) waits for a message sent to the specified notifier

Queues

QueueCreate(name) creates a queue with the specified name
QueueDestroy(name) destroys the specified queue
QueueGet(name,tmo) extracts an alement from the specified queue
QueueGetAll(name) extracts all elements from the specified queue
QueueLength(name) returns the number of elements in the specified queue
QueuePut(name,msg,tmo,stk) inserts an element to the specified queue
QueueTest(name) tests whether the specified queue exists
