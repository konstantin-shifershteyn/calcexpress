Signal Generation functions

The functions listed in this section are implemented as FuncVIs. When you call any of these function, CalcExpress calls the corresponding LabVIEW Advanced Analysis VI to perform the task. You must have LabVIEW FDS or PDS to be able to use these functions. If any function calls a LabVIEW VI that returns an error code, the function assigns the error code to the rtErrorCode variable

Click on a function name below for detailed information on the function.

function quick info corresponding LabVIEW VI
GWNoise returns an array containing Gaussian White Noise pattern Gaussian White Noise.vi
PRNoise returns an array containing Periodic Random Noise pattern Periodic Random Noise.vi
UWNoise returns an array containing Uniform White Noise pattern Uniform White Noise.vi
     
PChirp returns an array containing a Chirp Pattern Chirp Pattern.vi
PPulse returns an array containing a Pulse Pattern Pulse Pattern.vi
PSinc returns an array containing a Sinc Pattern Sinc Pattern.vi
PSine returns an array containing a Sine Pattern Sine Pattern.vi
     
SawtWave generates an array containing a Sawtooth wave Sawtooth Wave.vi
SineWave generates an array containing a Sine wave Sine Wave.vi
SquareWave generates an array containing a Square wave Square Wave.vi
TriangWave generates an array containing a Triangle wave Triangle Wave.vi
