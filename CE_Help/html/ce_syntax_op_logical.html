Logical-NOT operator:  !

The Logical-NOT operator produces the value 1 (true) if its operand is zero (false), and the value 0 (false) if its operand is non-zero (true). The operand is considered to have a 32-bit integer representation, for which Bit-keeping Conversion is applied.

Syntax:

! expression

The operator can work on scalars and arrays. It produces a value according to the polymorphism rules for unary operators.

By definition, the operator manipulates integer values. To perform the operation, CalcExpress converts its operand (or every element of the operand if it is an array) into a 32-bit integer value by applying Bit-keeping Conversion. After completing the operation, it performs the reverse conversion and stores the result in the floating-point representation (DBL).

Operand data types

DBL Number 1D Array of DBL 2D Array of DBL

click here to get general information on data types.

Example

x1 = !0;          /* x1 equals 1 */
x2 = !-1.1;       /* x2 equals 0 */
x3 = !(5.79 - 5); /* x3 equals 1 */

v0 = vector(0,2,0,3,5);
v1 = !v0;          /* v1 is array {1,0,1,0,0} */

Logical-AND operator:  &&

The Logical-AND operator produces the value 1 (true) if both operands are non-zero (true), and the value 0 (false) otherwise. Both operands are considered to have a 32-bit integer representation, for which Bit-keeping Conversion is applied.

Syntax:

expression1 && expression2

The operator can work on scalars, arrays, and combinations thereof. It produces a value according to the polymorphism rules for binary operators.

By definition, the operator manipulates integer values. To perform the operation, CalcExpress converts its operands (or every element of the operands if either is an array) into a 32-bit integer value by applying Bit-keeping Conversion. After completing the operation, it performs the reverse conversion and stores the result in the floating-point representation (DBL).

Operand data types

DBL Number 1D Array of DBL 2D Array of DBL

click here to get general information on data types.

Example

x1 = 0.9;  x2 = -10;
y1 = x1 && x2;          /* y1 equals 0 */
y2 = (x1>0)&&(x2<0);    /* y2 equals 1 */

v1 = vector(0,0,3,5);
v2 = vector(0,2,0,3);
v0 = v1 && v2;          /* v0 is array {0,0,0,1} */

Logical-OR operator:  ||

The Logical-OR operator produces the value 1 (true) if at least one of its operands is non-zero (true). If both operands are zero (false), it produces the value 0 (false). Both operands are considered to have a 32-bit integer representation, for which Bit-keeping Conversion is applied.

Syntax:

expression1 || expression2

The operator can work on scalars, arrays, and combinations thereof. It produces a value according to the polymorphism rules for binary operators.

By definition, the operator manipulates integer values. To perform the operation, CalcExpress converts its operands (or every element of the operands if either is an array) into a 32-bit integer value by applying Bit-keeping Conversion. After completing the operation, it performs the reverse conversion and stores the result in the floating-point representation (DBL).

Operand data types

DBL Number 1D Array of DBL 2D Array of DBL

click here to get general information on data types.

Example

x1 = 0.9;  x2 = -10;
y1 = x1 || x2;          /* y1 equals 1 */
y2 = (x1<0)||(x2>0);    /* y2 equals 0 */

v1 = vector(0,0,3,5);
v2 = vector(0,2,0,3);
v0 = v1 || v2;          /* v0 is array {0,1,1,1} */

Logical-XOR operator:  ^^

The Logical-XOR operator logically compares its operands. It produces the value 1 (true) if one operand is non-zero (true) and the other is zero (false). If both operands are either non-zero (true) or zero (false), the operator produces 0 (false). Both operands are considered to have a 32-bit integer representation, for which Bit-keeping Conversion is applied.

Syntax:

expression1 ^^ expression2

The operator can work on scalars, arrays, and combinations thereof. It produces a value according to the polymorphism rules for binary operators.

By definition, the operator manipulates integer values. To perform the operation, CalcExpress converts its operands (or every element of the operands if either is an array) into a 32-bit integer value by applying Bit-keeping Conversion. After completing the operation, it performs the reverse conversion and stores the result in the floating-point representation (DBL).

Operand data types

DBL Number 1D Array of DBL 2D Array of DBL

click here to get general information on data types.

Example

x1 = 2.5;  x2 = -10;
y1 = x1 ^^ x2;          /* y1 equals 0 */
y2 = (x1>0)^^(x2>0);    /* y2 equals 1 */

v1 = vector(0,0,3,5);
v2 = vector(0,2,0,3);
v0 = v1 ^^ v2;          /* v0 is array {0,1,1,0} */
