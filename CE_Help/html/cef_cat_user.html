Displaying and Interaction functions

The functions listed in this section are implemented as FuncVIs. When you call any of these function, CalcExpress calls relevant LabVIEW Function or VI to perform the task.

Click on a function name below for detailed information on the function.

function quick info
Beep(freq ,msec) emits a sound
DialogBox(var ,s1... ,sn) opens a dialog box containing a message, a string control, and two buttons
DialogBoxSL(var ,s1... ,sn) opens a dialog box containing a message, a single-line limited string control, and two buttons
MsgBox(x1... ,xn) opens a message box containing a message and one button
MsgBox2(x1... ,xn) opens a message box containing a message and two buttons
NumDialog(msg ,int, iniVal ,...) opens a dialog window to enter numeric value
Probe(x ,winName ,winX ,winY) opens probe windows to inspect arbitrary values
WFGraph(plot ,y ,x0 ,dx ,...) displays Waveform Graph
XYGraph(plot ,x ,y ,...) displays XY Graph
