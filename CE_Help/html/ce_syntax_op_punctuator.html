Sequential-Evaluation operator:  ,

The Sequential-Evaluation operator (also called the comma operator) is typically used to evaluate two or more expressions in cases where only one expression is expected. In addition, the comma is used as a delimiter for arguments in function calls and indices in the Subscript operator.

Syntax:

expression1 , expression2

The comma operator evaluates its two operands sequentially from left to right. CalcExpress completely evaluates the left-hand expression, including all side effects, before it starts evaluating the right-hand expression.

The comma operator allows any data types for operands, both predefined and user-defined (click here to get general information on data types). The result of the operation has the same data type and value as the right-hand operand.

Example

x = 4 * (y=1, y+2);     /* x equals 12, y equals 1 */

Expression Terminator:  ;

The Expression Terminator ( ; ) forms the expression-statement. It allows combining a few expressions into a single script. The Expression Terminator causes a preceding expression to be evaluated. Expression-statements are evaluated according to the rules described in Order of Script Evaluation topic.

NOTICE: Unlike an expression, the expression-statement does not produce a value that can be used for further evaluation.

Syntax:

expression ;

The expression can have any data type, both predefined and user-defined data types are alowed (click here to get general information on data types).

A semicolon ( ; ) must not appear within parentheses () or brackets [].

If an expression-statement consists of only semicolon, it is called the null-statement. Nothing happens when a null-statement is performed.

Example

x = 1.75;
y = sin(x) * exp(x);
x = 4, y = 2, z = x*y;  /* it is a single statement */
;;                      /* a couple of null-statements */

Parentheses:  (  )

Parentheses must always appear in pairs; i.e., each '(' must have a matching ')'. Parentheses are used for two purposes.

Parentheses are used to designate a function call if they follow an identifier. A list of function arguments is located within parentheses. See Function Call Syntax topic for more information.

Parentheses are used to change the order of expression evaluation. You can enclose any expression in parentheses to increase the precedence of the enclosed expression without changing its data type or value. It is guaranteed that the expression within parentheses will be evaluated, including any side effects, before it is used for further evaluation. Expressions within parentheses can themselves be enclosed in other parentheses. The deeper an expression is nested within parentheses, the higher its precedence is.

Example

x = 7 * (10+(3+5)/4);  /* x is equal to 84 */

You can use parentheses to clarify your intention when you use commas to form function arguments or array indexes.

Example

/* three arguments are passed to a function */
AnyFunction(a, (b=5, c=3, b+c), d);

/* returns a cell value in the first row and the second column */
AnyArray[(i1=1,i2=i1+1,i1) , i2];
