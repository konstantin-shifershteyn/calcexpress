File functions

The functions listed in this section are implemented as FuncVIs. When you call any of these functions, CalcExpress calls a LabVIEW File Function or VI to perform the task. Many functions assign an error code, which LabVIEW VIs return, to the rtErrorCode variable.

Click on a function name below for detailed information on the function.

function quick info

Path manipulations

FileBasePath(path) sets or returns a path that is used as base path if relative paths are used in the file functions
FileBuildPath(p1...,pn) builds a path from the specified components
FileGetAppPath(obj) returns some important paths
FileGetDir(path) returns the longest absolute directory path found in the specified path
FilePathToArray(path ,abs) converts the specified string path to array of path components
FileStripPath(path ,dir) returns either the last component of the specified path or the path without the last component

File I/O functions

FileLoad(path,var) reads a file and stores its contents at a string variable
FileLoadSS(path,var ,tr,fs,d)) reads a spreadsheet text file and stores the data at a variable
FileSave(path,mode,x) saves or appends the string data to the specified file
FileSaveSS(path,mode,x ,tr,fs,d) converts any data to the spreadsheet string, and then saves or appends the string to the specified file

Advanced functions

FileCopy(src,dst) copies the specified file or directory
FileDelete(path) deletes the specified file or directory
FileDialog(path,mod,msg,ptn,def) displays a dialog box to select a file or directory
FileListDir(path ,ptn,dir) returns the list of either file names or subdirectory names found in the specified directory
FileMove(src,dst) moves or renames the specified file or directory
FileNewDir(path) creates new directory
FileTest(path) tests the specified file or directory
