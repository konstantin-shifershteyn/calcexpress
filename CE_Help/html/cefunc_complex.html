arg

The function computes the phase angle (argument) of a complex number.

Implementation: FastFunc, FuncVI.

Syntax

arg(x)

Description

The function returns the argument of the complex x.
If complex x is represented as r * exp(i * j), the function returns j.

Parameters

The function can operate on scalars and arrays. The result is produced according to the polymorphism rules, except that the result always has a real representation (DBL). Formally, x can have the following data types:

DBL Number 1D Array of DBL 2D Array of DBL
CDB Number 1D Array of CDB 2D Array of CDB

If x has a non-complex representation, it is considered to be a complex number with an imaginary part equal to zero.

click here for general information on data types.

Return value

Depending on the data type of x, the function returns a value that has one of the following data types:

DBL Number 1D Array of DBL 2D Array of DBL

Example

x = 5;                // x is real 5
z = complex(x,x);     // z is complex (5,5)
a = arg( z );         // a is equal to p/4
b = arg( x );         // b is equal to 0

 

 

complex

The function creates a complex number in the rectangular notation.

Implementation: FastFunc, FuncVI.

Syntax

complex(x ,y)

Description

The function returns a complex number built from x and y in rectangular notation:

  x + i y.

y is an optional argument. If it is omitted in the function call, it is treated as zero.

Parameters

The function can operate on scalars, arrays and combinations thereof. The result is produced according to the polymorphism rules, except that the result always has a complex representation (CDB). Formally, x and y can have the following data types:

DBL Number 1D Array of DBL 2D Array of DBL

click here for general information on data types.

Return value

Depending on the data types of x and y, the function returns a value that has one of the following data types:

CDB Number 1D Array of CDB 2D Array of CDB

Example

v = vector(1,2,3);  // v is array {1,2,3}
z1 = complex(6);    // z1 is complex (6,0)
z2 = complex(v,1);  // z2 is array {(1,1),(2,1),(3,1)}
