Alias

The function controls the association of aliases with variables.

Implementation: FuncVI.

Syntax

Alias(name,alias ,vch)

Description

If the alias parameter contains a non-empty string, the function creates the specified alias and associates it with the variable specified by the name that is located in a variable context specified by the vch. If the variable already has an alias associated, the function renames its alias. If the alias contains an empty string, the function makes the variable unassociated with an alias.

The optional parameter vch specifies a handle of the variable context in which the variable name exists. If vch is omitted in the function call, the function uses the handle of the local variable context passed to a CalcExpress or CSE VI executing the script (the current local context). vch is ignored if name refers to a variable by an alias.

On success, the function returns zero. Otherwise, it returns the negated value of the VarMan Engine error code indicating an error reason. For example, it returns -11 if an invalid alias name is specified, -4 if an invalid context handle is specified, -2 if the specified variable is not found.

Parameters

data typedescription
name String Required parameter that specifies a variable name. In general, name has to comply with the VarMan name specifier syntax and can include a variable name or an alias, or both of them. See the Referring to variables topic for more information.
alias String Required parameter that specifies an alias name.
vch DBL Number Optional parameter that specifies the handle of the variable context where the specified variable exists. It is ignored if name refers to a variable by an alias. There are two special values for vch:
vch equal to 0 denotes the current local context.
vch equal to -1 denotes the global context.
By default, vch is equal to 0.

Return value

On success, the function returns zero. In case of an error, it returns a negative error code as described above.

The return value has the DBL Number data type.

Example

/* It is example of CSE script */
x = 0;
err = Alias("x", "Alias of x");
if (err) {
  lvErrorMessage("Alias() function", 7000-err);
  return err;
}

vclone, vcopy

The functions copy a value of the source variable to the destination variable.

Implementation: FastFunc.

Syntax

vclone(nameSrc,nameDst ,vchSrc ,vchDst)
vcopy(nameSrc,nameDst ,vchSrc ,vchDst)

Description

The functions assign a value of the variable nameSrc located in the variable context specified by vchSrc to the variable nameDst located in the context specified by vchDst. If nameSrc or nameDst refers to a variable by an alias, the respective context handle (vchSrc or vchDst) is ignored.

The functions work identically with the following exception. If the variable nameDst does not exist in the specified context, vclone function creates the variable with the same data type and value as nameSrc variable. On the contrary, vcopy function does not create a variable; instead, it returns an error code indicating that the destination variable does not exist.

If any of vchSrc or vchDst is omitted in the function call, the function uses the handle of the local variable context passed to a CalcExpress or CSE VI executing the script (the current local context).

The functions perform copying only if the destination variable has the same data type as the source variable; otherwise the functions return an error code indicating data type incompatibility.

On success, the functions return zero.

If an error occurs on a source variable, the functions return the negated value of the VarMan Engine error code. For example, they return -2 if a source variable is not found.

If an error occurs on a destination variable, the functions return the error code that is 1000 less than the negated value of the actual VarMan Engine error code. For example, they return -1004 if an invalid context handle is specified for a destination variable.

The functions return -1 (Invalid variable type error) if a source and a destination variables have different types.

Parameters

data typedescription
nameSrc
nameDst		 String Required parameters that specify names of the source variable (nameSrc) and the destination variable (nameDst). In general, nameSrc and nameDst have to comply with VarMan name specifier syntax and can include a variable name or an alias name, or both of them. See Referring to variables topic for more information.
vchSrc
vchDst		 DBL Number Optional parameters that specify handles of the variable contexts containing the source variable (vchSrc) and the destination variable (vchDst). If nameSrc or nameDst refers to a variable by an alias, the respective context handle is ignored. There are two special values for handles:
If a handle equals 0, it denotes the current local context.
If a handle equals -1, it denotes the global context.
By default, vchSrc and vchDst are equal to 0.

Return value

On success, the function returns zero. In case of an error, it returns a negative error code as described above.

The return value has the DBL Number data type.

Example

/*
It's example of CSE script that copies value of variable specified by RemVar and RemCtx to local variable LX10. Adapts type if necessary.
*/
RemVar = "X10";             /* name of non-local variable */
RemCtx = vch("Object B7");  /* non-local context */
LX10 = vectorn(0,0);        /* local 1D Array of DBL variable */
err = vcopy(RemVar, vnstr(LX10), RemCtx);
if (err) {            /* if copying is failed */
  if (err == -1) {    /* different types */
     /* copy to temporary variable */
     TmpVar = "buf";        /* variable name */
     vclone(RemVar, TmpVar, RemCtx);
     type = vtest(TmpVar);  /* get data type */
     if (type == 1)         /* DBL Number */
        LX10 = vector(idn(TmpVar)); /*scalar to array*/
     else if (type == 4)    /* 2D Array of DBL */
        LX10 = idn(TmpVar)[0];      /* the first row */
     else                   /* not DBL representation */
        MsgBox("Unsupported type: ",type);
     vundef(TmpVar);        /* destroy temporary variable */
  }
  else {
     MsgBox("Can't access variable. Err= ",err);
     return -1;
  }
}
probe( LX10 ); /* shows value of LX10 */

vset

The function assigns a variable value.

Implementation: FastFunc.

Syntax

vset(name,value ,vch)

Description

The function assigns value to the variable specified by name that is located in the variable context specified by vch.

The optional parameter vch specifies a handle of the variable context in which the variable name exists. If vch is omitted in the function call, the function uses the handle of the local variable context passed to a CalcExpress or CSE VI executing the script (the current local context). vch is ignored if name refers to a variable by an alias.

On success, the function returns zero. Otherwise, it returns the negated value of the VarMan Engine error code indicating an error reason. For example, it returns -4 if an invalid context handle is specified, -2 if the specified variable is not found, -1 if dat type of value differs from the data type of the variable.

Parameters

data typedescription
name String Required parameter that specifies a variable name. In general, name has to comply with the VarMan name specifier syntax and can include a variable name or an alias, or both of them. See the Referring to variables topic for more information.
value any type Required parameter that specifies a value to be assigned to the variable. value can have any data type providing that it is the same as data type of the variable name.
vch DBL Number Optional parameter that specifies the handle of the variable context where the specified variable exists. It is ignored if name refers to a variable by an alias. There are two special values for vch:
vch equal to 0 denotes the current local context.
vch equal to -1 denotes the global context.
By default, vch is equal to 0.

Return value

On success, the function returns zero. In case of an error, it returns a negative error code as described above.

The return value has the DBL Number data type.

Example

/*
It's example of CSE script that assigns a scalar value to the variable X10 located in a non-local context. Adapts data type if necessary.
*/
value = 5;
varName = "X10";
/* Determine a context handle by the context name */
varCntx = vch("Object A12 Parameters");
/* Determine a type of the variable */
type = vtest(varName, varCntx);
if (type < 0) {        /* If an error */
   if (type == -4) {
      MsgBox("The specified context doesn't exist");
      return -1;
   }
   /* create variable if it doesn't exist*/
   dbl(varName, value, varCntx);
}
else if (type == 1)    /* DBL Number */
   vset(varName, value, varCntx);
else if (type == 3)    /* 1D array of DBL */
   vset(varName, vector(value), varCntx);
else if (type == 4)    /* 2D array of DBL */
   vset(varName, matrix(value), varCntx);
else {
   MsgBox("Unsupported type of variable: ", type);
   return -2;
}

vtest

The function checks if a variable exists and returns its data type.

Implementation: FastFunc.

Syntax

vtest(name ,vch)

Description

The function looks for a variable that has the specified name in the variable context specified by vch.

The optional parameter vch specifies a handle of the variable context in which the variable name exists. If vch is omitted in the function call, the function uses the handle of the local variable context passed to a CalcExpress or CSE VI executing the script (the current local context). vch is ignored if name refers to a variable by an alias.

If the variable name is found, the function returns a data type code of the variable. If an error occurs, it returns the negated value of the VarMan Engine error code indicating an error reason. For example, it returns -2 if the variable is not found, or -4 if an invalid context handle is specified.

Parameters

  data type description
name String Required parameter that specifies a variable name. In general, name has to comply with the VarMan name specifier syntax and can include a variable name or an alias, or both of them. See the Referring to variables topic for more information.
vch DBL Number Optional parameter that specifies the handle of the variable context where the specified variable exists. It is ignored if name refers to a variable by an alias. There are two special values for vch:
vch equal to 0 denotes the current local context.
vch equal to -1 denotes the global context.
By default, vch is equal to 0.

Return value

The function returns either the data type of the variable or an error code (see above).

The return value has the DBL Number data type.

Example

varName = "X10";

/* Determines a context handle by the context name */
varCntx = vch("Object A12 Parameters");

/* Determine a type of the variable */
type = vtest(varName, varCntx);

if (type < 0) {        /* If an error */
   if (type == -4)
      MsgBox("The specified context doesn't exist");
   else
      MsgBox("Variable is not defined: ", varName);
}
else
   MsgBox("Code of variable type: ", type);
