Addition operator:  +

The addition operator causes its two operands to be added.

Syntax:

expression1 + expression2

The operator can work on scalars, arrays, and combinations thereof. It produces a value according to the polymorphism rules for binary operators.

Operand data types

DBL Number 1D Array of DBL 2D Array of DBL
CDB Number 1D Array of CDB 2D Array of CDB

click here to get general information on data types.

Example

x = 75; y = 55;
z = x + y - 30;            /* z equals 100 */
v1 = vector(100,200,300);  /* v1 is array {100,200,300} */
v2 = vector(10,20,30);     /* v2 is array {10,20,30}    */
vo = v1 + v2 + 5;          /* vo is array {115,225,335} */

Postfix Increment and Decrement operators:  ++ and --

Postfix Increment operator adds one to its operand, Postfix Decrement operator subtracts one from its operand. Both operators require the operand to be modifiable; i.e. refer to a variable or indexed-variable (see Subscript operator). If the operand's value is an array, increment or decrement operation is applied to every element of the array.

Postfix increment or decrement expression evaluates to the value of its operand prior to the respecive operator is applied. The increment or decrement operation occurs after the operand is evaluated. Both value and datatype of a postfix expression is the same as operand's value and datatype.

Syntax:

variable-expression ++
variable-expression --

The operators can work on scalars and arrays. They produce values according to the polymorphism rules for unary operators.

Operand data types

DBL Number 1D Array of DBL 2D Array of DBL

click here to get general information on data types.

Comments

The variable-expression must refer to an existing variable or indexed-variable.

Indexed-variable is an identifier (name of variable) followed by the Subscript operator. For example: x[1]

Example

x1 = 1;                  /* x1 is 1 */
x2 = 2 + x1++;           /* x1 is 2, x2 is 3 */
v1 = vector(1,2,3,4,5);  /* v1 is array {1,2,3,4,5} */
v2 = v1--;               /* v1 is array {0,1,2,3,4}, v2 is array {1,2,3,4,5} */
v2[0]--;                 /* v2 is array {0,2,3,4,5} */
x3 = v1[x1++];           /* x1 is 3, x3 is 2 */

Prefix Increment and Decrement operators:  ++ and --

Prefix Increment operator adds one to its operand, Prefix Decrement operator subtracts one from its operand. Both operators require the operand to be modifiable; i.e. refer to a variable or indexed-variable (see Subscript operator). If the operand's value is an array, increment or decrement operation is applied to every element of the array.

Prefix increment or decrement operator modifies its operand first and evalauates expression value afterwards. A value of a prefix expression is the new operand's value. Datatype of an expression value is the same as operand's value datatype.

Syntax:

++ variable-expression
-- variable-expression

The operators can work on scalars and arrays. They produce values according to the polymorphism rules for unary operators.

Operand data types

DBL Number 1D Array of DBL 2D Array of DBL

click here to get general information on data types.

Comments

The variable-expression must refer to an existing variable or indexed-variable.

Indexed-variable is an identifier (name of variable) followed by the Subscript operator. For example: x[1]

Example

x1 = 1;                  /* x1 is 1 */
x2 = 2 + ++x1;           /* x1 is 2, x2 is 4 */
v1 = vector(1,2,3,4,5);  /* v1 is array {1,2,3,4,5} */
v2 = --v1;               /* v1 is array {0,1,2,3,4}, v2 is array {0,1,2,3,4} */
--v2[0];                 /* v2 is array {-1,1,2,3,4} */
x3 = v1[++x1];           /* x1 is 3, x3 is 3 */
