beep

The function produces a sound.

Implementation: FuncVI.

Syntax

Beep( Freq ,msec )

Description

The function causes the system to emit a sound, which can be a default system alert or an audible tone with the specified frequency and duration, depending on the parameters passed to the function.

Parameters

data type description
Freq DBL Number Optional parameter specifies the frequency of the tone in Hertz. If its value is less than or equal to zero, it causes the default system alert. By default, it equals to 0.
msec DBL Number Optional parameter that specifies the duration of the tone in milliseconds. If its value is less than or equal to zero, it causes the default system alert. By default, it equals to 200.

Return value

The function returns 0 of the DBL Number data type.

Example

beep(3000,200); // 3kHz tone during 200ms
wait(1000);     // delay
beep();         // system alert

 

 

DialogBox, DialogBoxSL

The functions open a dialog window where a user can input information.

Implementation: FuncVI.

Syntax

DialogBox  (var ,s1 ... ,sn)
DialogBoxSL(var ,s1 ... ,sn)

Description

These functions open a dialog box that contains a message, a string control for input, and OK and Cancel buttons. The functions are identical, except that DialogBox provides a multi-line string control, while DialogBoxSL provides a single-line string control in a dialog window.

The message is formed by concatenating the optional string parameters s1...sn. The function supports an arbitrary number of these parameters.

The string control takes its initial value from the var variable. If the string control needs to be empty, assign an empty string to var before calling the function.

If a user clicks the OK button, the function saves the value of the string control at the var variable and returns 1 (TRUE). If a user either clicks the Cancel button or closes the dialog box, the function returns 0 (FALSE) without updating the var variable.

Parameters

data type description
var Identifier
(variable name)		 Required parameter specifies the name of an existing variable with the String data type. If a user presses the OK button, the function saves the value of the dialog's string control at this variable. If the variable does not exist or has a different data type, an error occurs. In addition, the initial value of the dialog's string control is taken from the var variable.
s1...sn String Optional parameters are concatenated to form the message in the dialog box.

Return value

The function returns a value of the DBL Number data type.

Example

/* It's example of CSE script */
for(;;) {
  /* set FilePath variable to the current folder */
  FilePath = FileBasePath();
  /* request a file name */
  if ( DialogBox(FilePath, "Enter file path")) {
    /* read a file if OK button is clicked */
    data = "";
    FileLoad( FilePath, data );
    /* exit from the 'for' loop if no error */
    if (!errno())
       break;
    /* display an error message and repeat */
    lvErrorMessage("FileLoad function");
  }
  else {
    /* terminate the script if Cancel button is clicked */
    return 0;
  }  /* end of if() */
}    /* end of for() */
/*
  process data here ...
 */
return 1;

 

 

MsgBox

The function opens a dialog window with a message and a button.

Implementation: FuncVI.

Syntax

MsgBox(x1 ... ,xn)

Description

The function opens a dialog window with a message built from the x1..xn parameters and the OK button.

The function supports an arbitrary number of the x parameters, which are all combined to form a message. If any x parameter is not a string, it is converted to a string before being added to the message.

The function always returns 1 (TRUE).

Parameters

data type description
x1 ... xn String
or
DBL Number		 Optional parameters are combined to form a message. Both string and numeric values are accepted. If any x is numeric, it is converted to a string using the format "%#_g".

Return value

The function returns a value of the DBL Number data type.

Example

x = erf(0.5);
MsgBox("The current value of x is ",x);

 

 

MsgBox2

The function opens a dialog window with a message and two buttons.

Implementation: FuncVI.

Syntax

MsgBox2(x1 ... ,xn)

Description

The function opens a dialog window with a message built from the x1..xn parameters and two buttons: OK and Cancel.

The function supports an arbitrary number of the x parameters, which are all combined to form a message. If any x parameter is not a string, it is converted to a string before being added to the message.

The function returns 1 (TRUE) if a user clicks the OK button; otherwise, it returns 0 (FALSE).

Parameters

data type description
x1 ... xn String
or
DBL Number		 Optional parameters are combined to form a message. Both string and numeric values are accepted. If any x is numeric, it is converted to a string using the format "%#_g".

Return value

The function returns a value of the DBL Number data type.

Example

/* It's example of CSE script */
for(;;) {
  /* set FilePath to the current folder */
  FilePath = FileBasePath();
  /* request a file name */
  if ( !DialogBox(FilePath, "Enter file path")) {
    /* exit if Cancel button is clicked */
    return 0;
  }
  /* come here if OK button is clicked */
  data = "";
  FileLoad( FilePath, data );
  /* break for-loop if there is no error */
  if (!errno())
     break;
  /* display an error message */
  if (!MsgBox2("The following error is occurred:\n",
      "---\n",
      lvErrorString(),
      "\n---",
      "\nDo you want to repeat?"))
  {
    /* exit if Cancel button is clicked in message box*/
    return -1;
  }
} /* end of for(;;) */
/*
  process data here ...
*/
return 1;

 

 

NumDialog

The functions open a dialog window asking to enter a numeric value.

Implementation: FuncVI.

Syntax

NumDialog(msg ,int ,iniVal , min ,max)

Description

This function opens a dialog window that contains a message, a numeric control for input, and OK and Cancel buttons.

If a user clicks the OK button, the function returns the value of the dialog's numeric control. If the user either clicks the Cancel button or closes the dialog, the function returns NaN.

Parameters

data type description
msg String Optional parameter that specifies the message to display.
int DBL Number Optional parameter. A non-zero value (TRUE) indicates that an integer value is expected. Otherwise, a fractional value is allowed. Default value is zero (FALSE).
iniVal DBL Number Optional parameter that specifies the initial value for the dialog's numeric control. If the value is out of the range specified by the min and max parameters, it will be forced to the range.
min DBL Number Optional parameter that specifies the minimum value permitted. By default, it is equal to -Inf.
max DBL Number Optional parameter that specifies the maximum value permitted. By default, it is equal to +Inf.

Return value

The function returns a value of the DBL Number data type.

Example

NumDialog("Enter a number in the range -1 to 1", 0, 0, -1, 1);

 

 

Probe

The function displays an input value in a probe window.

Implementation: FuncVI.

Syntax

Probe(x ,winName ,winX ,winY)

Description

The function opens a probe window that displays the value and data type of the x parameter. The function can display values of all predefined data types as well as user-defined data types. Values of predefined data types are displayed in the native LabVIEW format, while values of user-defined data types are displayed in the Flattened-To-String format.

The function can open an arbitrary number of probe windows. If the function is called with the winName parameter specified, it displays x in the probe window that has the winName title. If a probe window with that title already exists, the function updates it with new data; otherwise, it opens a new one. If winName is omitted in the function call, the function displays x in a default probe window.

Each probe window stays open until closed explicitly. It displays the most recent value passed to it and allows choosing the format and precision for numeric data, or the display style for string data.

The function returns 1 (TRUE) if x is successfully displayed in a probe window; otherwise, it returns 0 (FALSE).

Parameters

data type description
x any data type Required parameter that specifies the value to be displayed in a probe window.
winName String Optional parameter that specifies the title of the probe window where x is to be displayed. If winName is omitted in the function call, x is displayed in a default probe window.
winX,
winY		 DBL Number Optional parameters that specify the coordinates of the top-left corner of a probe window when it is opened for the first time; they do not affect a probe window if it is already open. The function coerces these values to integers.
winX and winY define the global desktop coordinates (if a system has more than one monitor). By default, these parameters are equal to NaN, which forces the function to open probe windows in cascade on the monitor where the Front Panel of the top-level VI executing the script is shown.

Return value

The function returns an execution status code of the DBL Number data type.

Example

num = 10;
str = "hello";
probe(num);   // default probe displays 10
probe(num*2); // default probe displays 20
probe(str);   // default probe displays "hello"
probe(num, "Numeric"); // "Numeric" titled probe displays 10
probe(str, "String");  // "String" titled probe displays "hello"

 

 

WFGraph

The function opens a window containing a Waveform Graph and displays the input data on the given plot of the graph.

Implementation: FuncVI.

Syntax

WFGraph(plot ,y ,x0 ,dx ,plotName ,winName ,winX ,winY)

Description

The function opens a window containing a Waveform Graph. Depending on the parameters provided, the function either displays the value of y on the target plot of the graph or clears the graph.

The function can open an arbitrary number of graph windows. If the function is called with the winName parameter specified, it displays data in the graph window that has the winName title. If a graph window with that title already exists, the function updates it with new data; otherwise, it opens a new one. If winName is omitted in the function call, the function displays data in a default graph window.

The function creates a graph window for each unique winName. Each graph window stays open until closed explicitly. A graph window displays the most recent data passed to each of its plots.

Parameters

data type description
plot DBL Number Optional parameter that specifies the index of a plot of the Waveform Graph on which y is to be displayed. If plot is not an integer, the function coerces it to an integer. If plot is greater than or equal to 0, the function displays data on the plot defined by this parameter, while other plots on the graph remain unaffected. If plot is negative, the function clears all plots of the WaveForm Graph. By default, plot is equal to -1.
y 1D Array of DBL Optional parameter that specifies the data to be displayed on the plot. The function clears the specified plot if this parameter is omitted in the function call or if an empty array is passed to it. By default, y is an empty array.
x0 DBL Number Optional parameter that specifies the initial value of the X scale. By default, x0 is equal to 0.
dx DBL Number Optional parameter that specifies the incrementation value of the X scale. By default, dx is equal to 1.
plotName String Optional parameter that specifies the name to be assigned to the plot. If plotName is omitted in the function call or is an empty string, the displayed plot takes the "Plot N" name, where N is the value of the plot parameter.
winName String Optional parameter that specifies the name of the graph window on which the function operates. If winName is omitted in the function call, the function operates on a default graph window.
winX,
winY		 DBL Number Optional parameters that specify the coordinates of the top-left corner of a graph window when it is opened for the first time; they do not affect a graph window if it is already open. The function coerces these values to integers.
winX and winY define the global desktop coordinates (if a system has more than one monitor). By default, these parameters are equal to NaN, which forces the function to open graph windows in cascade on the monitor where the Front Panel of the top-level VI executing the script is shown.

Return value

The function returns 0 of the DBL Number data type.

Example

x0 = 0;
dx = pi()/100;
/* array of x values in the range x0 to 2pi with dx step */
x = nvecifs(x0, pi(2), dx);
/* opens graph window and clears all plots of the graph */
WFGraph();
/* displays sin(x) on plot 0 */
WFGraph(0, sin(x), x0,dx, "SIN(x)");
/* displays the Bessel function of the 1st kind on plot 1 */
WFGraph(1, _jn(2,x), x0,dx, "Jn(x)");

 

 

XYGraph

The function opens a window containing an XY Graph and displays the input data on the specified plot of the graph.

Implementation: FuncVI.

Syntax

XYGraph(plot ,x ,y ,plotName ,winName ,winX ,winY)

Description

The function opens a window containing an XY Graph. Depending on the parameters provided, the function either displays the {x,y} data series on the target plot of the graph or clears the graph.

The function can open an arbitrary number of graph windows. If the function is called with the winName parameter specified, it displays data in the graph window that has the winName title. If a graph window with that title already exists, the function updates it with new data; otherwise, it opens a new one. If winName is omitted in the function call, the function displays data in a default graph window.

The function creates a graph window for each unique winName. Each graph window stays open until closed explicitly. A graph window displays the most recent data passed to each of its plots.

Parameters

data type description
plot DBL Number Optional parameter that specifies the index of a plot of the XY Graph on which the {x,y} input series are to be displayed. If plot is not an integer, the function coerces it to an integer. If plot is greater than or equal to 0, the function displays data on the plot defined by this parameter, while other plots on the graph remain unaffected. If plot is negative, the function clears all plots of the XY Graph. By default, plot is equal to -1.
x, y 1D Array of DBL Optional parameters that specify the data to be displayed on the plot; x defines values on the X-axis and y defines the respective values on the Y-axis. The function clears the specified plot if these parameters are omitted in the function call or if empty arrays are passed to them. By default, both x and y are empty arrays.
plotName String Optional parameter that specifies the name to be assigned to the plot. If plotName is omitted in the function call or is an empty string, the displayed plot takes the "Plot N" name, where N is the value of the plot parameter.
winName String Optional parameter that specifies the name of the graph window on which the function operates. If winName is omitted in the function call, the function operates on a default graph window.
winX,
winY		 DBL Number Optional parameters that specify the coordinates of the top-left corner of a graph window when it is opened for the first time; they do not affect a graph window if it is already open. The function coerces these values to integers.
winX and winY define the global desktop coordinates (if a system has more than one monitor). By default, these parameters are equal to NaN, which forces the function to open graph windows in cascade on the monitor where the Front Panel of the top-level VI executing the script is shown.

Return value

The function returns 0 of the DBL Number data type.

Example

x0 = 0;
dx = pi()/100;
/* array of x values in the range x0 to 2p with dx step */
x = nvecifs(x0, pi(2), dx);
/* opens graph window and clears all plots of the graph */
XYGraph();
/* displays a circle on plot 0 */
XYGraph(0, sin(x), cos(x), "Circle");
/* displays a spiral on plot 1 */
XYGraph(1, x/pi(2)*sin(x*4), x/pi(2)*cos(x*4), "Spiral");
