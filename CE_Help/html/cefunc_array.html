Terms used in description for Array functions

 

element denotes the following predefined data types:

DBL Number, CDB Number, String

1D Array denotes the following predefined data types:

1D Array of DBL, 1D Array of CDB, 1D Array of Strings

2D Array denotes the following predefined data types:

2D Array of DBL, 2D Array of CDB, 2D Array of Strings

base type is the data type of elements in an array or the data type of an integral value. It denotes the same predefined data types as the element term.

matrix

The function creates a 2D array from arbitrary parameters.

Implementation: FastFunc.

Syntax

matrix(x1 ,x2...,xn)

Description

The function appends an arbitrary number of parameters in left-to-right order to create a 2D array and returns the resulting array.

The function operates on an arbitrary number of arguments. All the actual parameters must have the same base type. If a parameter is not a 2D array, it is treated as if it were a 2D array with one row and the number of columns equal to the number of elements in that parameter.

The number of rows in the resulting array is equal to total number of rows in all the parameters. The number of columns is equal to the maximum number of columns among all input parameters. If necessary, the function fills in undefined elements with a default value (zero for numbers, an empty string for strings).

Parameters

data typedescription
x1 element
1D Array
2D Array		 Required parameter. The base type of x1 defines base type of the resulting array.
x2...xn element
1D Array
2D Array		 Optional parameters. All the actual parameters in a function call must have the same base type as x1.

Return value

The function returns a 2D Array with the same base type as x1.

Formally, the return value can have one of the following data types:

2D Array of DBL, 2D Array of CDB or 2D Array of Strings.

 

Example

ar1 = vector(1,2,3);
/* ar1 is 1D Array of DBL = {1,2,3} */
mtx = matrix(-1, ar1);
/* mtx is 2D Array of DBL containing:
 { {-1, 0, 0},
   { 1, 2, 3} }
*/
mtx = matrix(mtx, -2, vector(6,7,8,9));
/* now mtx contains:
 { {-1, 0, 0, 0},
   { 1, 2, 3, 0},
   {-2, 0, 0, 0},
   { 6, 7, 8, 9} }
*/
probe(mtx, "matrix");

matrixd

The function creates a diagonal matrix (2D array) with a given value on either the main diagonal or the anti-diagonal.

Implementation: FastFunc.

Syntax

matrixd(val,rows ,diag)

Description

The function creates a 2D array and assigns val to every element of the diagonal specified by the diag parameter. Both the number of rows and the number of columns in the resulting array are equal to the value of the rows parameter. The function returns the resulting array.

Parameters

data typedescription
val DBL Number
CDB Number
String		 Required parameter that specifies the data type of the array elements and the value of elements on the desired diagonal.
rows DBL Number Required parameter that specifies both the number of rows and number of columns in the resulting array. The function coerces it to the integer. If rows is less than or equal to zero, the function returns an empty array.

By default, diag is equal to 0 (main diagonal).

Return value

The function returns a 2D Array with the same base type as val.

Formally, the return value can have one of the following data types:

2D Array of DBL, 2D Array of CDB or 2D Array of Strings.

 

Example

 mtx1 is 2D Array of DBL containing:

   { 0, 0, 1 } }

/*
 mtx2 is 2D Array of DBL containing:
 { { 0, 0, 1 },
   { 0, 1, 0 },

nmtxifn, nmtxifs, nmtxins

The family of functions that create numeric 2D arrays populated with the sequential values.

Implementation: FastFunc.

Syntax

nmtxifn(init,rFinal,rNum  ,cFinal ,cNum)
nmtxifs(init,rFinal,rStep ,cFinal ,cStep)
nmtxins(init,rNum,  rStep ,cNum   ,cStep)

Description

The functions create a 2D array and fill it with sequential values according to the specified parameters. All these functions return the resulting array.

Every function creates an array with rNum rows and cNum columns, then it sets each element of the array equal to the value calculated using the formula:

element[i, j] = init + i * rStep + j * cStep  , where

i is a row index in the range from 0 to rNum-1.
j is a column index in the range from 0 to cNum-1.
 

Function specifics

The nmtxifn function does not have rStep and cStep parameters, it computes them with the formulas:

rStep = (rFinal - init) / ( rNum-1)
cStep = (cFinal - init) / ( cNum-1)

The nmtxifs function does not have rNum and cNum parameters, it computes them with the formulas:

rNum = 1 + floor( (rFinal - init) / rStep )
cNum = 1 + floor( (cFinal - init) / cStep )
for details on floor function click here.
 

Parameters

data typedescription
init DBL Number Required parameter that specifies the value of the element located in the first row and the first column of the resulting array.
rFinal DBL Number Required parameter that specifies the value to which the last element in the first column should equal or approximate.
cFinal DBL Number Optional parameter that specifies the value to which the last element in the first row should equal or approximate.
By default, cFinal is equal to rFinal.
rNum DBL Number Required parameter that specifies the number of rows in the resulting array. The functions coerce it to the integer. If rNum is less than or equal to 0, the resulting array is empty.
cNum DBL Number Optional parameter that specifies the number of columns in the resulting array. The functions coerce it to the integer. If cNum is less than or equal to 0, the resulting array is empty.
By default, cNum is equal to rNum.
rStep DBL Number Required parameter that specifies incrementation value along rows.
cStep DBL Number Optional parameter that specifies incrementation value along columns.
By default, cStepis equal to rStep.

Return value

All functions return the resulting matrix with the 2D Array of DBL data type.

 

Example

x1 = nmtxifn(1, 9,3, 10,4);
/* x1 is 2D Array of DBL containing:
  { { 1,  4,  7, 10 },
    { 5,  8, 11, 14 },
    { 9, 12, 15, 18 } }
*/
x2 = nmtxifs(0, 9,3 , 6,2);
/* x2 is 2D Array of DBL containing:
  { { 0,  2,  4,  6 },
    { 3,  5,  7,  9 },
    { 6,  8, 10, 12 },
    { 9, 11, 13, 15 } }
*/
x3 = nmtxins(0,4,5);
/* x3 is 2D Array of DBL containing:
  { { 0,  5, 10, 15 },
    { 5, 10, 15, 20 },
    {10, 15, 20, 25 },
    {15, 20, 25, 30 } }
*/
probe( x1, "x1" );
probe( x2, "x2" );
probe( x3, "x3" );

nvecifn, nvecifs, nvecins

The family of functions that create numeric 1D arrays pupulated with the sequential values.

Implementation: FastFunc.

Syntax

nvecifn(init,final ,num)
nvecifs(init,final ,step)
nvecins(init,num   ,step)

Description

The functions create a 1D array and fill it with sequential values according to the specified parameters. All these functions return the resulting array.

Every function creates an array that has num elements, then sets each element of the array equal to the value calculated using the formula:

element[i] = init + i * step , where i is in the range 0 to num-1.
 

Function specifics

The nvecifn function does not have step parameter, the function computes it with the formula:

step = (final - init) / ( num-1)

The nvecifs function does not have num parameter, the function computes it with the formula:

num = 1 + floor( (final - init) / step )
for details on floor function click here.
 

Parameters

data typedescription
init DBL Number Required parameter that specifies the value of the first element in the resulting sequence.
final DBL Number Required parameter that specifies the value to which the last element in the sequence should equal or approximate.
num DBL Number Parameter specifies the number of elements in the resulting array. The functions coerce it to the integer. If num is less than or equal to 0, the resulting array is empty. num is optional for nvecifn function that assumes 100 as the default value of num.
step DBL Number Optional parameter that specifies incrementation value in the resulting sequence.
nvecifs function assumes num equal to
  (final-init)/100 by default.
nvecins function assumes num equal to 1 by default.

Return value

All functions return the resulting sequence with the 1D Array of DBL data type.

Example

x1 = nvecifn(-pi(), pi(), 1000);
XYGraph(0, x1, sin(x1));
x2 = nvecifs(10,0, -0.5);
probe( x2, "x2" );
x3 = nvecins(0, 30, 1);
probe(factr(x3), "factorials");

rotate

The function rotates the elements in an array.

Implementation: FastFunc.

Syntax

rotate(x,n)

Description

The function rotates elements of x the number of places and in the direction specified by the n parameter and returns the resulting array.

Parameters

data typedescription
x 1D Array
2D Array		 Required parameter that specifies an input array. If x is a 2D array, the function treats it as if it were an 1D array that is compounded from the rows of the original 2D array.

The function returns a subset of a 2D array.

The function returns a subset of x started at the position specified by the rIdx and cIdx parameters, and containing the number of rows and the number of columns specified by the rows and cols parameters respectively.
