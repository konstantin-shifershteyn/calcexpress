Equality and Inequality operators:  ==   !=

The Equality (==) and Inequality (!=) operators compare their operands to test for equality (inequality) of operands. These operators do not follow the general polymorphism rules. They compare operands as a whole and produce a numeric scalar regardless of the operand data types. The result is 1 (true) if the tested relationship is true, and 0 (false) otherwise.

Syntax:

expression1 == expression2 (Equality operator)
expression1 != expression2 (Inequality operator)

Operand data types

The Equality and Inequality operators can compare operands of all predefined data types, as well as user-defined data types. The only requirement is that both operands must have the same data type.

click here to get general information on data types.

Example

x  = 5;
c1 = x == 10-7;            /* c1 equals 0 */
c2 = x != 10-7;            /* c2 equals 1 */

v1 = vector(1,2,3);
v2 = vector(1,2);
c3 = v1 == v2;             /* c3 equals 0 */
c4 = v1 == vector(v2, 8);  /* c4 equals 0 */
c5 = v1 == vector(v2, 3);  /* c5 equals 1 */

Relational operators:  >   >=   <   <=

The relational operators compare their first (left-hand) operand to their second (right-hand) operand to test the validity of the specified relationship. The result is 1 (true) if the tested relationship is true, and 0 (false) otherwise.

Syntax:

expression1 > expression2 (Greater operator)
expression1 >= expression2 (Greater-Or-Equal operator)
expression1 < expression2 (Less operator)
expression1 <= expression2 (Less-Or-Equal operator)

The operators can work on scalars, arrays, and combinations thereof. They produce values according to the polymorphism rules for binary operators.

Operand data types

DBL Number 1D Array of DBL 2D Array of DBL

click here to get general information on data types.

Example

x  = 5;
c1 = x <= 10-7;         /* c1 equals 0 */
c2 = x >  10-7;         /* c2 equals 1 */

v1 = vector(1,2,3,4,5);
v2 = vector(3,2,1);
c3 = v1 >  v2;          /* c3 is array {0,0,1} */
c4 = v1 <= 3;           /* c4 is array {1,1,1,0,0} */
