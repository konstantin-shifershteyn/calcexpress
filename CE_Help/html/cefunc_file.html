Relative paths

If you pass a relative file path to a CalcExpress file function, it uses the BasePath as the basis to transform the relative path to the absolute path required to perform a file operation. You can use FileBasePath function to define and evaluate the BasePath.

See File Paths topic for more information.

 

 

File paths

CalcExpress file functions operate on string parameters specifying file paths.

If you specify a file path as a string constant, you have to use double backslash characters (\\) as a separator of path components because the backslash starts an escape-sequence.

In addition, you can use the forward slash characters (/) instead of the backslashes. File functions recognize it and implicitly perform conversion to produce the valid file path. In the following example, the same path is specified by two valid ways:

path1 = "c:/mydir/myfile.txt";

path2 = "c:\\mydir\\myfile.txt";

Use of relative paths

To use relative file paths with file functions, you should define the BasePath that is used as the basis to build absolute file paths. Use FileBasePath function for this purpose. The function stores the BasePath at a variable in the local variable context used by a CalcExpress or CSE VI executing the script. Therefore, you have to call this function from every script that uses relative paths with the file functions.

If the BasePath is not defined, file functions use the LabVIEW Default Directory as the BasePath (you can define the Default Directory in the LabVIEW Options dialog).

Example

/* defines a base path */
FileBasePath("c:/mydir");
 
data = ""; //string variable
 
/* reads file c:\mydir\myfile.txt */
FileLoad("myfile.txt", data);
 
/* reads file c:\mydir\data\datafile.dat */
FileLoad("data/datafile.dat", data);
 
 

FileBasePath

The function defines or returns the BasePath that is used by file functions to build absolute file paths.

Implementation: FuncVI.

Syntax

FileBasePath(path)

Description

If the optional parameter path is specified in a function call, the function saves it to the BasePath.

See the File Paths topic for more information on how to specify paths for file functions.

The function returns the BasePath that always is absolute. If the BasePath is not defined, the function returns the LabVIEW Default Directory.

Parameters

data type description
path String optional parameter that specifies a path to be assigned to the BasePath.

Return value

The function returns the BasePath.

The return value has the String data type.

Example

/*1*/ FileBasePath("c:/myApp");
/*2*/ DataDir = FileBuildPath( FileBasePath(), "data" );
/*3*/ FileBasePath( FileGetAppPath() );

FileBuildPath

The function builds a path from its arguments.

Implementation: FuncVI.

Syntax

FileBuildPath(p1 ,p2 ... ,pn)

Description

The function returns a path made from arbitrary number of the specified components.

Parameters

data type description
p1 String or
1D Array of Strings		 required parameter that specifies leading components of a target path. To build an absolute path, the first component of p1 must be a drive name followed by a colon.
p2...pn String or
1D Array of Strings		 optional parameters that specify additional components of a target path.  

Return value

The function returns an absolute path if p1 parameter specifies an absolute path; otherwise the function returns a relative path.

The return value has the String data type.

Example

FileBasePath("c:/myApp");
/* DataDir is <c:\myApp\data> */
DataDir = FileBuildPath( FileBasePath(), "data" );
pathArr = FilePathToArray(DataDir);
pathArr = vector(pathArr, "myfile.txt");
/* filePath is <c:\myApp\data\myfile.txt> */
filePath = FileBuildPath(pathArr);

FileDialog

The function opens a dialog box to select the path to a file or directory.

Implementation: FuncVI.

Syntax

FileDialog(path ,mode ,prompt ,pattern ,defName)

Description

The function opens a dialog box to select the path to a file or directory. The function returns the selected path unless the user chooses the Cancel option.

See the File Paths topic for more information on how to specify paths for file functions.

The function assigns an error code returned by the used LabVIEW functions to the rtErrorCode variable. You can evaluate it using the errno function. If this function completes successfully, the error code is zero.

Parameters

data type description
path String optional parameter that specifies a start directory path. If it is omitted in a function call,  the BasePath is used as the start path.
mode DBL Number optional parameter that specifies kinds of files or directories that can be selected in the file dialog box. The following modes are possible:
0 :  only existing file
1 :  only non-existent file
2 :  existing or non-existent file
3 :  only existing directory
4 :  only non-existent directory
5 :  existing or non-existent directory
6 :  existing file (files in LLBs are allowed)
7 :  non-existent file (files in LLBs are allowed)
8 :  existing or non-existent file (files in LLBs are allowed)
By default, mode is equal to 2.
prompt String optional parameter that specifies a message that appears as the dialog box title.
pattern String optional parameter that restricts the files displayed in the dialog box. Only file names matching pattern are displayed. A pattern is like wildcards in Windows file names.
defName String optional parameter that specifies an initial file or directory name that appears in the dialog box.

Return value

The function returns the absolute path to the selected file or directory.

The return value has the String data type.

FileGetAppPath

The function returns some typical paths that can be useful to perform file operations.

Implementation: FuncVI.

Syntax

FileGetAppPath(obj)

Description

obj is an optional parameter that defines the absolute path to return, as follows:

0 :  the file path to the top-level VI. The path includes both VI name and LLB name, if any.
1 :  either the directory path or the LLB path of the top-level VI.
2 :  the directory path of the top-level VI. It is the default value.
3 :  the directory path of the current application, LabVIEW or a built executable.
4 :  the Temporary directory path that is defined in the LabVIEW Options dialog, the Paths page.
5 :  the Default directory path that is defined in the LabVIEW Options dialog, the Paths page.
6 :  the VI library directory path for the current application instance.
7 :  the CalcExpress VIs directory path.
8 :  the CalcExpress Examples directory path.
9 :  the CalcExpress Project directory path.

(*) The top-level VI is the first VI in the call chain of the CalcExpress or CSE VI executing this function.

Parameters

data type description
obj DBL Number optional parameter that specifies a kind of path to return. By default, it is equal to 2.

Return value

The function returns the absolute path.

The return value has the String data type.

Example

/* Sets the BasePath to directory containing top-level VI */
FileBasePath( FileGetAppPath() );

FileGetDir

The function searches for the longest existing directory path within the specified path.

Implementation: FuncVI.

Syntax

FileGetDir(path)

Description

The function returns the longest absolute path to an existing directory that can be found in the given path.

See the File Paths topic for more information on how to specify paths for file functions.

Parameters

data type description
path String required parameter that specifies either a file path or a directory path.

Return value

The function returns the absolute path to an existing directory found. If no a directory path is found, it returns an empty string.

The return value has the String data type.

Example

/*
  FileGetDir returns the directory path, that is
  <c:\myAppDir>
*/

FileListDir

The function returns the names of files or subdirectories found in the specified directory.

Implementation: FuncVI.

Syntax

FileListDir(path ,dir ,pattern)

Description

If the optional parameter dir is either zero (FALSE) or omitted in the function call, the function returns the names of files found in the path folder. Otherwise, it returns the names of subdirectories. Optionally, you can specify a pattern for names to match.

See the File Paths topic for more information on how to specify paths for file functions.

The function assigns an error code returned by the used LabVIEW functions to the rtErrorCode variable. You can evaluate it using the errno function. If this function completes successfully, the error code is zero.

Parameters

data type description
path String required parameter that specifies a directory path. If path is an empty string, the function opens a dialog box to select a directory.
dir DBL Number optional parameter. If its value coerced to an integer is zero, the function returns file names; otherwise, it returns directory names. By default, dir is equal to 0.
pattern String optional parameter that specifies a name pattern. Only names matching the pattern are returned. A pattern is like wildcards in Windows file names. By default, pattern is "*" (an asterisk character).

Return value

The return value has the 1D Array of Strings data type.

Example

/* It's example of CSE script */
FileBasePath("c:/myAppDir");
/*
  returns the list of file names in
  <c:\myAppDir\data>
*/
fileNames = FileListDir("data");
if (errno()) {
  /* handle an error */
  return -1;
}
/*
  returns the list of directory names in
  <c:\myAppDir>
*/
subdirNames = FileListDir( FileBasePath(), 1);

FileLoadSS

The function reads the specified spreadsheet file.

Implementation: FuncVI.

Syntax

FileLoadSS(path,var ,trans ,fmt ,dlm)

Description

The function reads the entire contents of a text file specified by the path parameter. The function considers the file contents like a spreadsheet string and converts it to a 2D array (let's call it "dataset") with a data type compatible with the data type of the var variable.

The function allows the var variable to have any predefined data type. Depending on the variable data type, it takes the value as follow:

  • If the var variable is a 2D array, the entire dataset is written to it. Herewith, 2D array is transposed if trans parameter is TRUE (non-zero).
  • If the var variable is an 1D array, either the first row (if trans is zero) or the first column (if trans is non-zero) of the dataset is written to it.
  • If the var variable is not an array, a cell value in the first row and the first column of the dataset is written to it.

The function uses Spreadsheet String To Array LabVIEW function to convert data. Refer to the help for this function for more information.

See the File Paths topic for more information on how to specify paths for file functions.

The function assigns an error code returned by the used LabVIEW functions to the rtErrorCode variable. You can evaluate it using the errno function. If this function completes successfully, the error code is zero.

Parameters

data type description
path String required parameter that specifies a source file to read. If path is an empty string, the function opens a dialog box to select a source file.
var Identifier
(variable name)		 required parameter. It must be an identifier that denotes an existing variable of any predefined data type. The function stores data to this variable. If the variable doesn't exist, an error is produced.
trans DBL Number optional parameter. If its value coerced to an integer is non-zero, the function transposes dataset before writing to the variable. By default, it equals 0.
fmt String optional parameter that specifies how to convert data from a string. The function uses the same format as Spreadsheet String To Array LabVIEW function. By default, it is "%f" for numbers and "%s" for strings.
dlm String optional parameter that specifies a delimiter used in a spreadsheet string. By default, it is "\t" (TAB).

Return value

If no errors occured, the function returns an absolute path of the source file; otherwise it returns an empty string.

The return value has the String data type.

Example

/* It's example of CSE script */
FileBasePath("c:/myAppDir/data");
/* 2D Array of DBL variable to store file data */
a2dbl("data");
/* reads file <c:\myAppDir\data\file.txt> */
fileName = FileLoadSS("file.txt", data);
if (errno()) {
  /* handle an error */
  MsgBox("Read file error");
  return -1;
}

FilePathToArray

The function converts the specified path to an array of the path components.

Implementation: FuncVI.

Syntax

FilePathToArray(path ,abs)

Description

The function returns an array containing the components of the specified path. If the path is a relative path, the result depends on the optional abs parameter.

If the path is a relative path and the abs parameter is non-zero, the function converts the path to an absolute path on the basis of the BasePath. Therefore, the resulting array will contain components of the absolute path. If the abs is zero or if it is omitted in a function call, the function will not convert a relative path to an absolute path.

See the File Paths topic for more information on how to specify paths for file functions.

Parameters

data type description
path String required parameter that specifies a path.
abs DBL Number optional parameter that specifies whether a relative path should be converted to an absolute path. By default, abs is equal to 0.

Return value

The return value has the 1D Array of Strings data type.

Implementation: FuncVI.

Syntax

FileSave(path,mode,str)

Description

The function writes str to the file specified by the path parameter. Depending on the mode parameter, the function either writes str to a new file or appends str to the existing file.

See the File Paths topic for more information on how to specify paths for file functions.

Return value

If no errors occured, the function returns an absolute path of the target file; otherwise, it returns an empty string.

FileSaveSS

The function writes arbitrary data to the specified spreadsheet file.

Implementation: FuncVI.

Syntax

FileSaveSS(path,mode,data ,trans ,fmt ,dlm)

Description

The function converts data to a spreadsheet string and writes the string to the file specified by the path parameter. Depending on the mode parameter, the function either writes the string to a new file or appends it to the existing file.

The function allows data to have an arbitrary data type. If data has a predefined data type, the function converts data to a spreadsheet string according to the format specified by the fmt parameter. If fmt is omitted, it assumes the default format: "%f" for numeric data or "%s" for string data. The function uses Array To Spreadsheet String LabVIEW function to convert data to a string. Refer to the help for this function for more information.

If data is not a 2D array, the function converts it to a 2D array before formatting to a spreadsheet string; herewith the 2D array is transposed if trans parameter is TRUE (non-zero).

If data has a user-defined data type, the function writes it without any conversion, in the Flattened-To-String format.

See the File Paths topic for more information on how to specify paths for file functions.

The function assigns an error code returned by the used LabVIEW functions to the rtErrorCode variable. You can evaluate it using the errno function. If this function completes successfully, the error code is zero.

Parameters

data type description
path String required parameter that specifies the target file. If path is an empty string, the function opens a dialog box to select a file.
mode DBL Number required parameter that specifies a mode to write file. The following modes are possible:
0 = create a new file. If the file already exists, an error occurs.
1 = create a new file. If the file already exists, replace it.
2 = append data to an existing file. If the file doesn't exist, create a new file.
The function coerces mode to an integer. If mode differs from the specified values, it assumes 0.
data any type required parameter that specifies the data to be written to the file.
trans DBL Number optional parameter. If its value coerced to an integer is non-zero, the function transposes 2D data before converting to a string. By default, it equals 0.
fmt String optional parameter that specifies how to convert data to a string. The function uses the same format as Array To Spreadsheet String LabVIEW function. By default, it is "%f" for numbers and "%s" for strings.
dlm String optional parameter that specifies a delimiter to use in a spreadsheet string. By default, it is "\t" (TAB).

Return value

If no errors occured, the function returns an absolute path of the target file; otherwise it returns an empty string.

The return value has the String data type.
