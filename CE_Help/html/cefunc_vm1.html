a1cdb

The function creates a variable of the 1D Array of CDB data type if it does not exist.

Implementation: FastFunc.

Syntax

a1cdb(name ,value ,vch)

Description

The function creates a variable of the 1D Array of CDB data type with the specified name and assigns an initial value to it. If a variable with the given name already exists, the function does not affect it in any way, but returns a status code of -3.

The optional parameter vch specifies a handle of the variable context in which the variable is to be created. If vch is omitted in the function call, the function works with the local variable context used by a CalcExpress or CSE VI executing the script (the current local context).

The function returns zero if it successfully creates the variable. Otherwise, it returns the negated value of the VarMan Engine error code indicating an error reason. For example, it returns -10 if an invalid variable name is specified, -4 if an invalid context handle is specified, -3 if the variable already exists.

Parameters

  data type description
name String Required parameter that specifies a variable name. In general, name has to comply with the VarMan name specifier syntax and can include a variable name or an alias, or both of them. See the Referring to variables topic for more information.
value 1D Array of CDB Optional parameter that specifies an initial value to be assigned to the variable. value is ignored if the variable already exists. By default, value is an empty array.
vch DBL Number Optional parameter that specifies a handle of the variable context where the variable should be created. There are two special values for vch:
vch equal to 0 denotes the current local context.
vch equal to -1 denotes the global context.
By default, vch is equal to 0.

Return value

On success, the function returns zero. In case of an error, it returns a negative error code as described above.

The return value has the DBL Number data type.

Examples

/* Attempts to create the variable called Array_1. On the success, it assigns an empty array to the variable. */
a1cdb("Array_1");

/* Attempts to create the variable called Array_2. On the success, it assigns the initial value to the variable. */
a1cdb("Array_2", vectorn( complex(0,-1) ,10) );

/* Attempts to create the variable called Array_3. On the success, it assigns value of Array_2 to the variable. */
name = "Array_3";
a1cdb(name, Array_2);

/* Attempts to create the variable called Array_5; the variable name is produced by sform function that is similar to Format Into String LabVIEW function. On the success, it assigns the value of Array_2 multiplied by 2 to the variable. */
name  = "Array";
index = 5;
a1cdb(sform("%s_%d",name, index), 2*Array_2);
