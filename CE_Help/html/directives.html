Parsing Directives

Parsing Directives are used in CSE scripts and CalcExpress expressions to configure parsing parameters. They are intended to override the default parameters of the CSE or CalcExpress parser VIs.

Parsing Directives can appear in any situation where they can be interpreted as dedicated tokens. They are not processed if they appear within comments, string constants, or character constants.

Parsing Directives are only used during the parsing phase. They do not result in any additional code execution during script run or expression evaluation.

$NCOFF Disables Named Constants. After this directive, any further appearance of Named Constants is ignored, and they will be treated as regular identifiers (variable names). This setting remains in effect until the end of parsing or until the $NCON directive is reached.
$NCON Enables Named Constants. After this directive, Named Constants are treated in the regular way. This setting remains in effect until the end of parsing or until the $NCOFF directive is reached.
 

Example

$NCOFF  /* disables Named Constants */

/* creates or assigns the M_2PI variable */
M_2PI = 2 * 3.14;

/* shows value of the variable */
probe(M_2PI, "M_2P variable");

$NCON  /* enables Named Constants */

/* shows value of the Named Constant */
probe(M_2PI, "M_2P constant");
