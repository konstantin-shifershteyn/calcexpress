vhAttach

The function creates a history for the specified variable.

See the Variable History topic for information on history maintenance.

Implementation: FuncVI.

Syntax

vhAttach(name,size ,vch ,enaWrID)

Description

The function creates a history for the variable specified by name that is located in the variable context specified by vch.

The optional parameter vch specifies a handle of the variable context in which the variable name exists. If vch is omitted in the function call, the function uses the handle of the local variable context passed to a CalcExpress or CSE VI executing the script (the current local context). vch is ignored if name refers to a variable by an alias.

On success, the function returns zero. Otherwise, it returns the negated value of the VarMan Engine error code indicating an error reason. For example, it returns -2 if the specified variable is not found, -8 if the variable already has a history attached, -9 if an invalid history size is specified.

Parameters

data typedescription
name String Required parameter that specifies a variable name. In general, name has to comply with the VarMan name specifier syntax and can include a variable name or an alias, or both of them. See the Referring to variables topic for more information.
size DBL Nunber Required parameter that specifies the maximum number of values that the history can hold. A history is maintained as a circular buffer. It always contains the most recent values. The function coerces size to be an integer.
vch DBL Number Optional parameter that specifies the handle of the variable context where the specified variable exists. It is ignored if name refers to a variable by an alias. There are two special values for vch:
vch equal to 0 denotes the current local context.
vch equal to -1 denotes the global context.
By default, vch is equal to 0.
enaWrID DBL Number Optional parameter that enables, if TRUE (non-zero), or disables, if FALSE (zero), the retention of Writer IDs within the variable history.
By default, enaWrID is equal to 1 (TRUE).

Return value

On success, the function returns zero. In case of an error, it returns a negative error code as described above.

The return value has the DBL Number data type.

Example

/* It is example of CSE script */
x = 0;
/* attach history to x0 (size=100) */
err = vhAttach("x", 100);
if (err) {
  lvErrorMessage("vhAttach() function", 7000-err);
  return err;
}
/* changing x value in the loop */
while(x < 10)
  x += random();
/* display history of x */
vhShow("x");

vhConf, vhConfCx

The functions change configuration parameters of a history of the specified variable.

See the Variable History topic for information on history maintenance, and VHistory - History Controller.vi for information about the configuration parameters.

Implementation: FuncVI.

Syntax

vhConf(name ,tStep ,tGate ,vcond ,delta ,rmin ,rmax)
vhConfCx(name ,vch ,tStep ,tGate ,vcond ,delta ,rmin ,rmax)

Description

The functions save the specified parameters to a history configuration of the variable specified by name. The functions work identically, except that the vhConfCx function has the vch parameter while vhConf does not.

The optional parameter vch specifies a handle of the variable context in which the variable name exists. If vch is omitted in the function call, the function uses the handle of the local variable context passed to a CalcExpress or CSE VI executing the script (the current local context). vch is ignored if name refers to a variable by an alias.

On success, the function returns zero. Otherwise, it returns the negated value of the VarMan Engine error code indicating an error reason. For example, they return -2 if the specified variable is not found, -7 if the variable does not have a history attached.

Parameters

data typedescription
name String Required parameter that specifies a variable name. In general, name has to comply with the VarMan name specifier syntax and can include a variable name or an alias, or both of them. See the Referring to variables topic for more information.
vch DBL Number Optional parameter that specifies the handle of the variable context where the specified variable exists. It is ignored if name refers to a variable by an alias. There are two special values for vch:
vch equal to 0 denotes the current local context.
vch equal to -1 denotes the global context.
By default, vch is equal to 0.
tStep DBL Number Optional parameter that specifies a value, in milliseconds, of the time step condition. By default, it is equal to 0.
tGate DBL Number Optional parameter that specifies a value, in milliseconds, of the time gate condition. By default, it is equal to 0.
vcond DBL Number Optional parameter that specifies a kind of value condition. By default, it is equal to 0.
delta DBL Number Optional parameter that specifies the Delta parameter of the value condition. By default, it is equal to 0.
rmin DBL Number Optional parameter that specifies the RangeMin parameter of the value condition. By default, it is equal to 0.
rmax DBL Number Optional parameter that specifies the RangeMax parameter of the value condition. By default, it is equal to 0.

Return value

On success, the function returns zero. In case of an error, it returns a negative error code as described above.

The return value has the DBL Number data type.

vhQuery

The function returns history of the specified variable.

See the Variable History topic for information on history maintenance.

Implementation: FuncVI.

Syntax

vhQuery(name,dVar ,tVar ,rev ,nval ,vch)

Description

The function reads a history of the variable specified by name and writes the history values and time stamps to the variables specified by the dVar and tVar parameters respectively.

The optional parameter vch specifies a handle of the variable context in which the variable name exists. If vch is omitted in the function call, the function uses the handle of the local variable context passed to a CalcExpress or CSE VI executing the script (the current local context). vch is ignored if name refers to a variable by an alias.

The variable defined by the name parameter must have one of the following data types: DBL Number, CDB Number or String. Respectively, the variable defined by the dVar parameter must have data type: 1D Array of DBL, 1D Array of CDB or 1D Array of Strings. If tVar parameter is not omitted, it must be a name of variable that has 1D Array of DBL data type.

All the parameters that specify variable names (name, dVar and tVar) have the String data type. An empty string can be passed to either dVar or tVar parameter if the corresponding data is not of interest. In general, a variable name should comply with the VarMan name specifier syntax and can include a variable name or an alias, or both of them. See the Referring to variables topic for more information.

All the referenced variables must exist in order to the function succeed. However, the function does not cause a CalcExpress runtime error if it cannot find any of them. Instead, it returns a non-zero code to indicate an error reason.

On success, the function returns zero. Otherwise, it returns the negated value of the VarMan Engine error code indicating an error reason. For example, it returns -2 if any of the specified variable is not found, -7 if name variable does not have a history attached.

Parameters

data typedescription
name String Required parameter that specifies a variable name. In general, name has to comply with the VarMan name specifier syntax and can include a variable name or an alias, or both of them. See the Referring to variables topic for more information.
dVar String Required parameter that specifies the name of a variable to write historic values. It is allowed to pass an empty string as the value for the dVar parameter if historic values are not needed. The variable specified by dVar must be an one-dimensional array with a data type that agrees with the data type of the variable specified in name.
tVar String Optional parameter that specifies the name of a variable to write history time stamps. It is allowed to pass an empty string as the value for the tVar parameter if time stamps are not needed. Elements in the tVar variable contain time stamps for the respective elements in the dVar variable.
rev DBL Number Optional parameter that specifies an order in which returned history values and time stamps are arranged. If it is non-zero, the history is arranged in reversed chronological order; i.e. the first element in dVar variable contains the last value assigned to name variable. By default, rev is equal to 1.
nvals DBL Number Optional parameter that specifies number of the newest history values should be returned. By default, nvals is equal to -1 to return entire history.
vch DBL Number Optional parameter that specifies the handle of the variable context where the specified variable exists. It is ignored if name refers to a variable by an alias. There are two special values for vch:
vch equal to 0 denotes the current local context.
vch equal to -1 denotes the global context.
By default, vch is equal to 0.

Return value

On success, the function returns zero. In case of an error, it returns a negative error code as described above.

The return value has the DBL Number data type.

Example

/* It is example of CSE script */
x = 0;
/* attach history to x0 (size=100) */
err = vhAttach("x", 100);
if (err) {
  lvErrorMessage("vhAttach() function", 7000-err);
  return err;
}
/* changing x value in the loop */
while(x < 10)
  x += random();
/* create variable for history data */
a1dbl("x_history");
/* retrieve history values */
err = vhQuery("x", "x_history", "", 0);
if (err) {
  lvErrorMessage("vhQuery() function", 7000-err);
  return;
}
// display history on waveform graph
wfGraph(0, x_history);

vhShow, vhShowCx

The functions opens a probe window displaying a history of the specified variable.

See the Variable History topic for information on history maintenance.

Implementation: FuncVI.

Syntax

vhShow(name ,winName ,winX ,winY)
vhShowCx(name ,vch ,winName ,winX ,winY)

Description

The functions open a probe window that displays a history of the variable specified by name. The functions work identically, except that the vhShowCx function has the vch parameter while vhShow does not.

The optional parameter vch specifies a handle of the variable context in which the variable name exists. If vch is omitted in the function call, the function uses the handle of the local variable context passed to a CalcExpress or CSE VI executing the script (the current local context). vch is ignored if name refers to a variable by an alias.

The functions can open arbitrary number of probe windows. If a function is called with the specified winName parameter, it displays a history in the probe window that has winName title; new probe window is created if it is necessary. If winName is omitted in a function call, the function displays a history in the default probe window.

Each probe window is opened until end user explicitly close it. A probe window displays a history that existed at a moment when the respective function call has been performed. In a probe window, it is possible to choose a format and precision of numeric data, or display style of string data.

The functions return 1 (TRUE) if a probe window was successfully opened; otherwise they return 0 (FALSE).

Parameters

data typedescription
name String Required parameter that specifies a variable name. In general, name has to comply with the VarMan name specifier syntax and can include a variable name or an alias, or both of them. See the Referring to variables topic for more information.
vch DBL Number Optional parameter that specifies the handle of the variable context where the specified variable exists. It is ignored if name refers to a variable by an alias. There are two special values for vch:
vch equal to 0 denotes the current local context.
vch equal to -1 denotes the global context.
By default, vch is equal to 0.
winName String Optional parameter that specifies a title of the probe window. If winName is omitted in a function call, the function displays a history in the default probe window.
winX,
winY		 DBL Number Optional parameters that specify the coordinates of the top-left corner of a probe window when it is opened for the first time; they do not affect a probe window if it is already open. The function coerces these values to integers.
winX and winY define the global desktop coordinates (if a system has more than one monitor). By default, these parameters are equal to NaN, which forces the function to open probe windows in cascade on the monitor where the Front Panel of the top-level VI executing the script is shown.

Return value

The functions return an execution status code (see above).

The return value has the DBL Number data type.

Example

/* It is example of CSE script */
x = 0;
/* attach history to x0 (size=100) */
err = vhAttach("x", 100);
if (err) {
  lvErrorMessage("vhAttach() function", 7000-err);
  return err;
}
/* changing x value in the loop */
while(x < 10)
  x += random();
/* display history of x */
vhShow("x");
