Signal Processing and Measurement functions

Most of the functions listed in this section are implemented as FuncVIs. When you call any of these functions, CalcExpress calls the corresponding LabVIEW Advanced Analysis VI to perform the task. You must have LabVIEW FDS or PDS to be able to use these functions. If a function calls a LabVIEW VI that returns an error code, the function assigns the error code to the rtErrorCode variable.
