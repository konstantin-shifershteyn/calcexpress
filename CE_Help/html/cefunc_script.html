abort

The function aborts execution of CalcExpress and CSE scripts.

Implementation: FastFunc, FuncVI.

Syntax

abort()

Description

If this function is called in either CalcExpress or CSE script, the execution of the script immediately terminates with an "aborted" error. This will also abort the execution of all higher-level scripts in the call chain of the script.

Parameters

No parameters.

Return value

No return.

 

 

Call     (CSE scripts only)

The function calls a CSE script from a CSE script.

Implementation: FuncVI.

Syntax

Call(ScriptPath ,parSpec1 ,parSpec2 ...)

Description

The function reads the specified script file and executes the script. The called script has its own unique Variable Context that does not interfere with the context of the calling script. In addition, the function allows the transfer of values (variable values or constants) between the variable contexts of the calling and called scripts.

The function can be used to call a script recursively, but it is your responsibility to ensure that the script has a mechanism to stop the recursive calls to avoid infinite recursion. The CallLevel function can be used to determine the current level of nesting in a script's call chain.

The function returns the value that the called script returns using the return statement.

Parameters

data type description
ScriptPath String Required parameter specifies either an absolute or relative path to the script file that is to be called. If the path is relative, the function looks for the file in locations relative to
1) a directory where the calling script resides
2) directories assigned as the search paths
A file path of the top-level script has to be specified before CSE starts executing; for this, use CSE - Script Path & Search Paths.vi. Search paths can be defined before starting the top-level script (CSE - Script Path & Search Paths.vi) as well as they can be defined during a script execution (SearchPath function). A called script inherits search paths from its caller. A file path of the script can be retrieved with the call of ScriptPath function.
 
parSpec

 String Optional parameters specify variables to be transferred to and-or from the called script. The function supports arbitrary number of parSpec parameters (including zero).

parSpec format

    "LocalVar  Cmd  CalledVar"  , where

LocalVar  is the name of variable in context of the calling script.
CalledVar is the name of variable in context of the called script.
Cmd    defines an operation:
    >>  : LocalVar is to be copied to CalledVar before the called script starts.
    <<  : CalledVar is to be copied to LocalVar after the called script completes.
    <>  : combines >> and << operations.

Remarks

1)  if the destination variable in an operation does not exist, it will be created with the same data type and value as the source variable.
2)  if the destination variable exists, it must have the same data type as the source variable.
3)  it is possible to combine a few parSpecs within a single string using '&' character as a delimiter.
4)  it is possible to specify a numeric constant instead of a source variable name.

Return value

The function returns the value that the called script returns using the return statement.

Example

/*1*/ err = call("calc.txt", "var >> x", "-2.5 >> y", "result << z");
/*2*/ err = call("calc.txt", "var >> x  & -2.5 >> y  & result << z");

Also see

Exec function,  CSE Script Control functions,  File functions.

 

 

CallLevel     (CSE scripts only)

The function returns the nesting level of the current CSE script in its call chain.

Implementation: FuncVI.

Syntax

CallLevel()

Description

The function returns a positive integer that represents the nesting level of the current script in its call chain.

The top-level script has the nesting level of zero. If a script is called directly from the top-level script, its nesting level equals to 1, and so on. In general, each call of the Call or Exec function increases the nesting level of the called script by one compared to its caller. This also applies to recursive script calls.

Parameters

No parameters.      

Return value

The function returns a positive integer value of the DBL Number data type.

Also see

CSE Script Control functions.

 

 

Exec     (CSE scripts only)

The function executes a CSE script in framework of another CSE script.

Implementation: FuncVI.

Syntax

Exec(ScriptPath)

Description

The function reads the specified script file and executes the script. The function works similar to the Call function except it does not create a variable context for the called script. Instead, the called script inherits the context of its caller; this means the callee has direct access to the variables of the caller.

The CallLevel function can be used to determine the current level of nesting in a script's call chain.

The function returns the value that the called script returns using the return statement.

Parameters

data type description
ScriptPath String Required parameter specifies either an absolute or relative path to the script file that is to be called. If the path is relative, the function looks for the file in locations relative to
1) a directory where the calling script resides
2) directories assigned as the search paths
A file path of the top-level script has to be specified before CSE starts executing; for this, use CSE - Script Path & Search Paths.vi. Search paths can be defined before starting the top-level script (CSE - Script Path & Search Paths.vi) as well as they can be defined during a script execution (SearchPath function). A called script inherits search paths from its caller. A file path of the script can be retrieved with the call of ScriptPath function.

Return value

The function returns the value that the called script returns using the return statement.

Example

err = exec("a_script.txt");

Also see

Call( ), CSE Script Control functions, File functions.

 

 

ScriptPath     (CSE scripts only)

The function returns a file path associated with a CSE script.

Implementation: FuncVI.

Syntax

ScriptPath(level)

Description

The function returns a file path associated with a running CSE script. Depending on the level parameter, it returns either the path of the current script or the path of one of its callers.

The function returns the requested path.

Parameters

data type description
level String Optional parameter specifies the nesting level of desired script in the call chain of the current script. Depending on its value, the function returns:

-2 or less: the path of the current script (by default)
-1 : the path of the calling script
0 : the path of the top-level script
1 or greater : a script path at the specified nesting level

If level is equal to or greater than the current script level, the current script path is returned. By default, if level is omitted, the function returns the current script path.

Return value

The function returns a String with the requested path.

Also see

CSE Script Control functions, File functions.

 

 

SearchPath     (CSE scripts only)

The function defines or returns directory paths where to search for CSE script files.

Implementation: FuncVI.

Syntax

SearchPath(path1 ,path2 ...)

Description

The function adds the specified path(s) to the search paths used by the current script. The Call and Exec functions use these search paths to find the script file if its path is not absolute.

Note that a called script inherits the search paths from its caller.

The function returns the stored search paths.

Parameters

data type description
path String Optional parameters specify directory paths. The number of path parameters is arbitrary (including zero). If there is no one path specified, the function merely returns the stored search paths.
(*) Relative paths are converted to absolute paths by appending them to the directory where the top-level VI resides.

Return value

The function returns a 1D Array of Strings with the search paths used by the current script.

Also see

CSE Script Control functions, File functions.
