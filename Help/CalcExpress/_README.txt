CALCEXPRESS TOOLKIT FOR LABVIEW
==============================================================================

Thank you for installing CalcExpress and welcome to our community!

This product features a rich, quarter-century history of active development 
and successful use across many organizations worldwide. The author sincerely
hopes you find it highly valuable and effective for your engineering work.


## LINKS & REPOSITORY (Source Code, Updates & Changelog)
------------------------------------------------------------------------------
Starting with Version 4.0, the entire CalcExpress project is open-source under 
the terms of the MIT License. You can find the source code for the entire
project, including VIs, the engine DLLs, and all assets on the official GitHub
page:

https://github.com/konstantin-shifershteyn/calcexpress


## MAINTENANCE, BUG REPORTING & SUPPORT
------------------------------------------------------------------------------
CalcExpress is a mature product provided strictly "AS IS", WITHOUT WARRANTY OF 
ANY KIND. The individual author no longer guarantees technical support,
ongoing updates, or direct email troubleshooting.

If you encounter an edge-case bug, wish to propose a feature optimization, 
or want to contribute a code fix, you are enthusiastically welcome to submit 
a formal Pull Request directly on our GitHub project page.
